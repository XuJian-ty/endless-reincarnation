# 阶段一：关卡内最小可玩 — 需求说明书

## 一、目标

在现有「主菜单 → 选档 → 进关卡 + 玩家移动与动作」基础上，实现：

1. **关卡内出现可攻击的敌人**（先做一种近战小怪）。
2. **玩家攻击能造成伤害**：普攻/蓄力/空中普攻/下落攻击等命中敌人时，按战斗公式扣血。
3. **敌人死亡后**：玩家获得经验与金币，精英/守卫者按配置概率掉落物品并进入背包。
4. **满包时**：无法拾取新物品，掉落物保留在地上（本阶段可先做「满包不生成掉落」或简单提示）。

达成「进关 → 打怪 → 掉钱/掉装 → 升级」的最小闭环。

---

## 二、敌人

### 2.1 五种敌人与「同一控制器」

- **五种敌人类型**（枚举 `EnemyType`）：近战小怪（MeleeMinion）、远程小怪（RangedMinion）、精英（Elite）、守卫者（Guardian）、Boss。
- **共用同一个控制器**：五种敌人都挂 **同一个** `EnemyController` 组件；区别只在于挂的 **EnemyStatsSO** 不同：
  - 在 SO 里把 **Type** 选成对应类型（Melee Minion / Ranged Minion / Elite / Guardian / Boss），并填该类型的基础属性、金币、经验。
  - 精英/守卫者可在预制体上再配 **Drop Table**、**Weapon Source**（小怪/Boss 只掉金币或按需求书单独处理）。
- 因此：做 **5 份 EnemyStatsSO**（如 `EnemyStats_MeleeMinion`、`EnemyStats_Elite`…），做 **5 个敌人预制体**（或更多），每个预制体挂同一个 **EnemyController**，Inspector 里 **Stats SO** 拖入对应的那一份 SO 即可。

### 2.2 类型与配置（SO 字段）

- 使用现有 **EnemyStatsSO**：配置 `enemyId`、`displayName`、**Type**（五种之一）、基础生命/攻击/防御/移速、`goldMin`/`goldMax`。
- **新增**：`EnemyStatsSO` 增加 **基础经验值** `baseExp`（击杀后玩家获得）。运行时写入 `EnemyRuntimeStats.expReward`，难度不放大经验。

### 2.3 行为（本阶段简化）

- 敌人有 **当前血量**（`EnemyRuntimeStats.currentHp`），受击时扣血。
- **死亡条件**：`currentHp <= 0`。
- 死亡时：
  1. 发事件 **GameEvents.EnemyDied**（参数可带 enemyId、position、enemyType，供后续扩展）。
  2. 若是守卫者，发 **GameEvents.GuardianDied**（无参）。
  3. 玩家获得 **经验**：`PlayerModel.AddExp(expReward)`。
  4. 玩家获得 **金币**：在 `goldMin`～`goldMax` 间随机，加到 `PlayerModel.Gold`。
  5. **掉落**：仅精英/守卫者参与掉落表 Roll；小怪只掉金币。掉落物进入 `PlayerModel.Inventory`（武器用 `AddWeapon`，堆叠用 `AddStackable`）；满包则本次不掉落（或仅金币照常）。
- 死亡后：敌人 GameObject 禁用或回收到对象池（本阶段可先 `SetActive(false)` 或 `Destroy`）。

### 2.4 难度

- 敌人 **生命/攻击/防御/移速** 按当前关卡难度与 **DifficultyScalingSO** 放大（沿用 `EnemyStatsSO.GetScaled`）。
- 难度来源：`GameStateMachine.GetInstance().CurrentRun.difficulty`；无 Run 时默认 1。

## 三、玩家攻击与命中

### 3.1 哪些动作能造成伤害

- 地面普攻（1～4 段）、蓄力释放、空中普攻、下落攻击着陆。
- 技能与受击不在本阶段做伤害判定（可后续接同一套逻辑）。

### 3.2 判定方式

- 在 **攻击命中时刻**（动画事件或现有 `OnAttackHit` / `OnAirAttackHit` / `OnChargeReleaseHit` / `OnFallAttackHit`）做一次 **范围检测**：
  - 以玩家位置 + 朝向为参考，做 **OverlapSphere** 或 **SphereCast**，检测「敌人」层。
- 范围内所有带 **EnemyController** 的物体视为命中，每个目标只结算一次伤害（本帧内不重复结算同一实例）。

### 3.3 伤害与吸血

- 使用 **CombatCalculator.CalculateDamage**：
  - 攻击方：`PlayerModel.Stats`
  - 技能倍率：普攻 1，蓄力/下落攻击等可配置（本阶段可统一 1）
  - 防御方：`EnemyRuntimeStats.defense`
  - 随机数：`System.Random` 或注入委托
- 得到 `finalDamage`、`isCrit`、`lifeStealHeal`。
- 对敌人：调用 `EnemyController.ApplyDamage(finalDamage)`（内部用 `EnemyRuntimeStats.WithDamageApplied` 更新血量）。
- 对玩家：`PlayerModel.Heal(lifeStealHeal)`。

### 3.4 实现位置

- 在 **表现层** 增加一个负责「攻击命中时做检测并结算伤害」的组件（如 `PlayerCombat` 或挂在 `PlayerController` 上的逻辑），订阅 `PlayerAnimatorController` 的命中事件，执行 Overlap + 伤害计算 + 敌人扣血 + 玩家吸血。不把公式或敌人引用写进状态机内部，保持状态机只负责动作与状态切换。

## 四、掉落

### 4.1 谁掉什么

- **近战/远程小怪**：只掉金币（已在 2.2）。
- **精英**：金币 + 按 **DropTableSO**（按关卡 `levelIndex`）Roll 一次，可能掉武器/药剂/仙露；掉落的武器用 `WeaponSO.Roll(rarity, rng)` 生成 **WeaponInstance**，加入背包。
- **守卫者**：必掉 1 天赋点（本阶段可先只做「发 GuardianDied」，天赋点在 UI 层显示时再接）；不掉武器/药剂（需求书约定）。

### 4.2 满包

- 若 `!Inventory.CanAddWeapon()` 或 `!CanAddStackable(...)`，则本次不掉落该物品（只加金币与经验）；可打日志或后续做「地面掉落物」时再拾取。

---

## 五、数据与配置

### 5.1 已有

- **EnemyStatsSO**：基础属性、goldMin/Max；需增加 **baseExp**。
- **EnemyRuntimeStats**：struct，含 `WithDamageApplied`；需增加 **expReward**。
- **DifficultyScalingSO**：难度系数。
- **DropTableSO**：按关卡权重 Roll 物品类型（如 weapon_common、potion_hp 等）。
- **WeaponSO**：`Roll(rarity, rng)` 生成 WeaponInstance。

### 5.2 关卡与难度

- 难度：`GameStateMachine.GetInstance().CurrentRun?.difficulty ?? 1`。
- **DifficultyScalingSO**：由关卡场景中的 **LevelBootstrapper** 或单独配置物体持有，敌人生成/初始化时读取（本阶段可在 EnemyController 上 SerializeField 引用同一份 SO）。

---

## 六、场景与预制体约定

- **玩家**：已有 PlayerController + 动画、攻击事件。
- **敌人**：
  - 预制体带 **EnemyController**、Collider（用于 Overlap 检测）、可选 **EnemyStatsSO** 引用（或由生成器注入）。
  - 敌人放在 **Layer「Enemy」**，玩家攻击 Overlap 时只检测该层。
- **相机/光照**：沿用现有关卡场景。

---

## 七、本阶段不做的

- 敌人 AI（移动、寻路、主动攻击）：可先静止或简单朝玩家移动，后续阶段再做。
- 地面掉落物实体、拾取交互：满包时仅「不加入背包」，不做地面模型。
- Buff 选择、技能树、商店、Boss 流程：阶段二及之后。

---

## 八、验收标准

1. 进关卡后场景内有至少 1 个敌人，玩家普攻/蓄力/空中普攻/下落攻击能打中并扣血。
2. 敌人血量为 0 后死亡（消失或禁用），玩家获得经验与金币；精英（若本阶段有）死亡时按表掉落武器或药剂并进入背包。
3. 伤害与吸血符合 CombatCalculator 公式；难度提高时敌人更耐打/伤害更高。
4. 满包时不再往背包加武器/堆叠，经验与金币照常。
