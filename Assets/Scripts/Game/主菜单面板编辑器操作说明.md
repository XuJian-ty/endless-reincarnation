# 主菜单面板：编辑器里一步一步怎么做

依据**功能需求说明书**：**一、开始界面**（存档数量不限、起名后新建、加载时选已有存档）。

- 主界面提供四个入口：**新的游戏**、**加载存档**、**声音设置**、**退出游戏**。
- **新的游戏**：点击后弹出**起名面板**，输入玩家名字并点击确认后，**直接创建一份新存档**并保存，然后弹出**加载面板**显示进度条，**异步加载关卡一**；加载完成后进入第一关。
- **加载存档**：点击后弹出**存档选择面板**，仅列出**已保存过的存档**（无空槽），每项显示**玩家名字**；点击某一存档后弹出加载面板，异步加载完成后进入**该存档退出游戏时保存的场景**。
- **声音设置**：打开**主菜单声音设置面板**（仅主界面背景音乐滑块），见《声音设置面板编辑器操作说明》。
- **退出游戏**：退出应用（编辑器下为停止运行）。

## 一、主菜单面板（MainMenuPanel）预制体

### 1.1 在场景里做出主菜单

1. **建根物体**
   - 打开任意有 **Canvas** 的场景（或从 Project 把 **Resources/UI/Canvas** 拖进 Hierarchy）。
   - 在 **Canvas** 下选 **Bot** 或 **Mid**（主菜单通常用 Mid 或单独一层），**右键 → UI → Panel**，命名为 **MainMenuPanel**（Panel 自带 RectTransform + Image，可直接当底图或删掉 Image 再自建 Bg）。

2. **挂脚本**
   - 选中 **MainMenuPanel**，**Add Component** 搜索 **Main Menu Panel**，添加 **Main Menu Panel (Script)**。  
   - 脚本不需要在 Inspector 里拖任何引用，四个按钮通过**名字**自动绑定（见下）。

3. **做背景（可选）**
   - 选中 MainMenuPanel，**右键 → UI → Image**，命名 **Bg**，铺满父物体（Anchor 拉伸，四边 0），Color 可半透明或纯色。

4. **做四个按钮（名字必须一致）**
   - 在 **MainMenuPanel** 下 **右键 → UI → Button**，命名 **Btn_NewGame**，把按钮子物体上的 **Text** 改为「**新的游戏**」。
   - 再 **右键 → UI → Button**，命名 **Btn_LoadGame**，文字改为「**加载存档**」。
   - 再 **右键 → UI → Button**，命名 **Btn_Settings**，文字改为「**声音设置**」。
   - 再 **右键 → UI → Button**，命名 **Btn_Quit**，文字改为「**退出游戏**」。
   - 排布：用 **Vertical Layout Group** 挂在 MainMenuPanel 上（Spacing 约 10），或手动上下排好。**不要**在 Inspector 里给按钮手动挂 OnClick，**BasePanel** 会按名字自动注册，**MainMenuPanel** 已用 **RegisterClick** 绑定逻辑。

5. **做成预制体**
   - 在 **Hierarchy** 里选中 **MainMenuPanel**（整棵，含 Bg 和四个按钮），拖到 **Project 的 Resources/UI/** 下，松开后生成预制体。
   - 在 Project 里把预制体名字改为 **MainMenuPanel**（必须与代码里 `PanelNames.MainMenu` 一致，即 "MainMenuPanel"）。
   - 回到 Hierarchy，删掉场景里这棵 MainMenuPanel（运行时会由 UIManager 从预制体加载）。

### 1.2 确认 Resources/UI 下已有

- **Resources/UI/Canvas**（UIManager 会加载）
- **Resources/UI/MainMenuBackground**（主界面背景，见 §2.1）
- **Resources/UI/MainMenuPanel**（主菜单面板）
- **Resources/UI/NamePanel**（起名面板，见 §4）
- **Resources/UI/SaveListPanel**（存档选择面板，见 §5）
- **Resources/UI/MainMenuSoundPanel**（主菜单声音设置，仅主界面 BGM 滑块，见《声音设置面板编辑器操作说明》）

若还没有 **MainMenuBackground**、**NamePanel**、**SaveListPanel**、**MainMenuSoundPanel**，需先按各自说明做好并放到 Resources/UI/。

## 二、主菜单场景（MainMenu）

### 2.1 主界面背景（从 UI 资源加载）

主界面背景和主菜单面板一样，**从 Resources/UI 加载**。进入游戏时**只显示主界面背景**，不显示主菜单；主界面背景上除底图外还有一个「**点击任意键继续...**」的提示（图片或文字），用户按下任意键后才显示主菜单面板并隐藏该提示。选槽加载关卡时只隐藏主菜单和槽选择，**不隐藏主界面背景**，因此加载时只会看到主界面背景 + 下方加载进度条。

1. **做主界面背景预制体**
   - 打开任意有 **Canvas** 的场景（或从 Project 把 **Resources/UI/Canvas** 拖进 Hierarchy）。
   - 在 **Canvas** 下选 **Bot**（或任意层，运行时会挂到 Bot），**右键 → UI → Panel**，命名为 **MainMenuBackground**。
   - 选中 **MainMenuBackground**，**Add Component** 搜索 **Main Menu Background Panel**（或搜 **MainMenuBackgroundPanel**），添加该脚本。Unity 里组件名由类名 `MainMenuBackgroundPanel` 显示为「Main Menu Background Panel (Script)」。
   - **右键 → UI → Image**，命名 **Bg**，铺满父物体（Anchor 拉伸，四边 0），设为背景图或纯色。
   - **「点击任意键继续...」提示**：在 **MainMenuBackground** 下 **右键 → UI → Image**（或 Text），命名 **PromptClickToContinue**。若是 Image，把「点击任意键继续...」艺术字图片拖到 Source Image；若是 Text，输入这段文字并设置字体与样式。摆到合适位置（如屏幕中下）。
   - 在 Inspector 里把 **PromptClickToContinue** 拖到 **Main Menu Background Panel** 脚本的 **Prompt Click To Continue** 字段。脚本会在显示时保持该物体为激活，用户按下任意键或鼠标左键后将其隐藏并弹出主菜单面板。
   - 在 Hierarchy 里选中 **MainMenuBackground**（整棵），拖到 **Project 的 Resources/UI/** 下，预制体名字改为 **MainMenuBackground**（与 `PanelNames.MainMenuBackground` 一致）。
   - 删掉场景里这棵（运行时会由 UIManager 加载）。

2. **流程说明**
   - **GameEntry.Start** 只调用 **ShowPanel&lt;MainMenuBackgroundPanel&gt;(MainMenuBackground, Bot)**，此时只显示主界面背景 + 「点击任意键继续...」。
   - 用户**按下任意键或点击鼠标**后，**MainMenuBackgroundPanel** 隐藏提示并调用 **ShowPanel&lt;MainMenuPanel&gt;(MainMenu, Mid, …)**，主菜单四个按钮出现。
   - 起名确认或选择存档后加载时，只隐藏主菜单与起名/存档面板，不隐藏 MainMenuBackground，故加载时只剩主界面背景 + LoadingPanel。

### 2.2 场景里只要一个入口脚本

1. **放 GameEntry**
   - 在 **MainMenu** 场景的 **Hierarchy** 里 **右键 → Create Empty**，命名为 **GameEntry**（或任意名）。
   - 选中该物体，**Add Component** 搜索 **Game Entry**，添加 **Game Entry (Script)**。  
   - **GameEntry** 不需要在 Inspector 里拖任何引用：它只在 **Start** 里加载主界面背景（**ShowPanel&lt;MainMenuBackgroundPanel&gt;**）；主菜单面板在用户「点击任意键继续」后由 **MainMenuBackgroundPanel** 再显示。

2. **不需要在场景里放 Canvas 或主菜单 UI**
   - UIManager 从 **Resources/UI/Canvas** 加载 Canvas，从 **Resources/UI/** 加载主界面背景和主菜单面板；主菜单场景里只需放 **GameEntry**。

3. **保存场景**
   - **Ctrl+S** 保存主菜单场景。

### 2.3 运行流程简述

- 进入 **MainMenu** 场景 → **GameEntry.Start** 执行 → **UIManager** 加载 Canvas + **MainMenuBackground** → 只显示**主界面背景**和「**点击任意键继续...**」。
- 用户**按下任意键或点击** → 提示隐藏，**MainMenuPanel** 被加载并显示，主菜单四个按钮叠在背景上。
- 点击「**新的游戏**」→ 打开 **NamePanel**（起名面板）→ 输入名字并确认 → 创建新存档并保存 → 隐藏起名与主菜单、显示 **LoadingPanel** → 异步加载关卡一 → 加载完成后关闭 LoadingPanel 并进入第一关。
- 点击「**加载存档**」→ 打开 **SaveListPanel**（存档选择面板，仅列出已有存档、每项显示玩家名）→ 点击某一存档 → 隐藏存档列表与主菜单、显示 LoadingPanel → 异步加载该存档记录的关卡场景 → 加载完成后关闭 LoadingPanel 并进入该场景。
- 点击「**声音设置**」→ 打开 **MainMenuSoundPanel**（仅主界面 BGM 滑块）。
- 点击「**退出游戏**」→ 编辑器下停止运行，打包后退出应用。

## 三、加载进度条面板（LoadingPanel）预制体

选「新的游戏」起名确认或「加载存档」选择某一存档后，主菜单面板会隐藏，只保留主界面背景，同时显示**加载进度条**；关卡场景异步加载过程中进度条会更新，加载完成后自动关闭。

**逻辑说明**：只需**两张图**——**填充图在下、遮罩图（原先的底图）在上**，长度都在编辑器里设好，**脚本不改任何图的尺寸**。脚本只改「遮罩图所在容器」的**可见范围**：在区间内从左到右逐渐收窄该范围（相当于逐渐隐藏遮罩图），露出下面的填充图。两个值（Fill Range Start / End）用来设置这段**区间**。

**LoadingPanel 层级说明**

```
LoadingPanel（根，挂 Loading Panel 脚本）
├── ProgressBar（进度条容器）
│   ├── FillRect（填充区间容器，脚本只设其锚点区间）
│   │   └── ProgressFill（填充图，Image，长度在编辑器里设好，脚本不改）
│   ├── CoverMaskRect（遮罩图容器，挂 Rect Mask 2D；脚本只改其可见范围，不改内部图片尺寸）
│   │   └── CoverImage（遮罩图/原底图，Image，长度在编辑器里设好、右对齐，脚本不改）
│   └── （可选）ProgressBg（整条底图，若需要边框等）
└── ProgressText（百分比文字，Text）
```

- **FillRect**、**CoverMaskRect** 同级；**CoverMaskRect** 排在 **FillRect 下面**，遮罩图才画在填充图上面。
- 遮罩图（CoverImage）在编辑器里**右对齐**（Anchor 靠右），这样裁切时是从左边开始「隐藏」。
- 脚本绑定：**Fill Rect** → FillRect，**Cover Mask Rect** → CoverMaskRect，**Progress Text** → ProgressText。

### 3.1 在场景里做出 LoadingPanel

**步骤 1：建根物体并挂脚本**

1. 打开 **MainMenu** 场景（或任意带 Canvas 的场景）。
2. 在 **Hierarchy** 里选中 **Canvas**，**右键 → UI → Panel**，新建一个 Panel。
3. 在 Hierarchy 里选中这个新 Panel，在 **Inspector** 顶部的名字改成 **LoadingPanel**。
4. 选中 **LoadingPanel**，在 Inspector 底部点 **Add Component**，搜索 **Loading Panel**，点击 **Loading Panel (Script)** 添加。

**步骤 2：做进度条容器**

1. 在 Hierarchy 里 **右键点 LoadingPanel** → **Create Empty**，名字改为 **ProgressBar**。
2. 选中 **ProgressBar**，在 Inspector 的 **Rect Transform** 里：**Anchor** 选底部居中或底部拉伸，**Pos Y**、**Height**、**Left/Right** 按你想要的进度条位置调好。
3. （可选）若需要整条底图/边框：**右键点 ProgressBar** → **UI → Image**，命名 **ProgressBg**，铺满 ProgressBar；脚本不引用它。

**步骤 3：做填充图（在下层，长度在编辑器里设好，脚本不改）**

1. 在 Hierarchy 里 **右键点 ProgressBar** → **Create Empty**，名字改为 **FillRect**。
2. 选中 **FillRect**，Rect Transform：**Anchor** 选左右拉伸、上下拉伸，**Left/Right/Top/Bottom** 都设 0。脚本只改 FillRect 的锚点区间 [start,end]，不碰子物体。
3. 在 Hierarchy 里 **右键点 FillRect** → **UI → Image**，名字改为 **ProgressFill**。
4. 选中 **ProgressFill**，在 **Image** 里选**填充条图**，**Image Type** 选 **Sliced**。Rect Transform 选「拉伸铺满父物体」，**Left/Right/Top/Bottom** 都 0。——**脚本不会改填充图尺寸**。

**步骤 4：做遮罩图（在上层，长度在编辑器里设好，脚本只改「可见范围」）**

1. 在 Hierarchy 里 **右键点 ProgressBar** → **Create Empty**，名字改为 **CoverMaskRect**。
2. 选中 **CoverMaskRect**，**Add Component** → 搜索 **Rect Mask 2D** → 添加。
3. 在 **CoverMaskRect** 下 **右键 → UI → Image**，名字改为 **CoverImage**（遮罩图，即原先的底图）。
4. 选中 **CoverImage**：**Image** 里选遮罩/管道底图；Rect Transform 里 **Anchor 选右对齐**（例如右边拉伸或右中），**长度在编辑器里设成和填充段一致**，**脚本不改**。这样裁切会从左边开始「隐藏」。
5. 把 **CoverMaskRect** 拖到 **FillRect 下面**（在 Hierarchy 里排在 FillRect 下方），遮罩才画在填充图上面。
6. 选中根 **LoadingPanel**，在 **Loading Panel (Script)** 里：**Fill Rect** 拖成 FillRect，**Cover Mask Rect** 拖成 CoverMaskRect。

**步骤 5：设置区间（两个值）**

- 在 **Loading Panel (Script)** 里：  
  - **Fill Range Start**（0～1）：这段区间的**左边界**（占整条比例）。  
  - **Fill Range End**（0～1）：这段区间的**右边界**。  
- 整条就设 0 和 1；只要中间一段就设如 0.2 和 0.8。脚本只在这个区间内「从左到右逐渐隐藏遮罩图」。脚本会用这两个值确定「填充 + 遮挡」生效的那一段，并按 0%～100% 逐渐缩小遮挡层，露出填充图。

**步骤 6：百分比文字**

1. Hierarchy 里 **右键点 LoadingPanel**（或 ProgressBar 同级）→ **UI → Text**，名字改为 **ProgressText**。
2. 把 ProgressText 拖到进度条下方，改字体、字号、颜色。
3. 选中 **LoadingPanel**，把 **ProgressText** 拖到 **Progress Text** 槽。

**步骤 7：做成预制体**

1. 在 **Project** 里打开 **Assets/Resources/UI/**（没有就新建）。
2. 从 **Hierarchy** 把 **LoadingPanel**（整棵）拖进 **Resources/UI**。
3. 在 Project 里把预制体名字改成 **LoadingPanel**。
4. Hierarchy 里删掉场景里这一棵。

---

**如果你已经有一个旧的 LoadingPanel（用 CoverRect 遮挡层的）**

1. 在 **Project** 里双击 **Resources/UI/LoadingPanel** 预制体。
2. 在 **ProgressBar** 下新建 **Create Empty**，名字改为 **CoverMaskRect**；给 CoverMaskRect **Add Component → Rect Mask 2D**。
3. 把原来的 **CoverRect**（或原底图）拖成 **CoverMaskRect** 的**子物体**，改名为 **CoverImage**；在 CoverImage 的 Rect Transform 里设成**右对齐**，长度与填充段一致。
4. 在 **Loading Panel (Script)** 里：**Fill Rect** 仍是 FillRect；**Cover Mask Rect** 拖成 **CoverMaskRect**（不再用 Cover Rect）。
5. **Fill Range Start / End** 设好区间（0 和 1 = 整条）。保存预制体。

**脚本绑定**：**Fill Rect** = FillRect，**Cover Mask Rect** = CoverMaskRect，**Progress Text** = ProgressText；**Fill Range Start / End** = 区间（0～1）。层级见本节开头「LoadingPanel 层级说明」。

### 3.2 流程说明

- 进入 **MainMenu** → 主界面背景 + 主菜单面板。
- 用户选「新的游戏」起名确认或「加载存档」选某一存档 → 对应面板隐藏、主菜单隐藏 → **UIManager.ShowPanel&lt;LoadingPanel&gt;** 显示加载条 → **GameStateMachine.LoadGame(saveId, …)** 异步加载场景（ScenesMgr 触发「进度条更新」，LoadingPanel 已订阅）→ 场景加载完成后 **HidePanel(Loading)**，进入关卡。

## 四、起名面板（NamePanel）预制体

主菜单点击「**新的游戏**」后弹出**起名面板**，玩家输入名字并点击确认后，系统创建新存档并异步加载关卡一。

### 4.1 在场景里做出 NamePanel

**步骤 1：建根物体并挂脚本**  
在 **Canvas** 下 **右键 → UI → Panel**，命名为 **NamePanel**。选中 **NamePanel**，**Add Component** 搜索 **Name Panel**，添加 **Name Panel (Script)**。

**步骤 2：做背景（可选）**  
在 **NamePanel** 下 **右键 → UI → Image**，命名 **Bg**，铺满父物体，可半透明。

**步骤 3：做输入框与按钮**

**步骤 4：做成预制体**

## 五、存档选择面板（SaveListPanel）预制体

主菜单点击「**加载存档**」后弹出**存档选择面板**，仅列出**已保存过的存档**，每项显示**玩家名字**（及关卡）；点击某一项后异步加载该存档场景。

### 5.1 在场景里做出 SaveListPanel

**步骤 1：建根物体并挂脚本**  
在 **Canvas** 下 **右键 → UI → Panel**，命名为 **SaveListPanel**（Panel 自带 RectTransform 与 Image，适合做面板根并阻挡射线）。选中 **SaveListPanel**，**Add Component** 搜索 **Save List Panel**，添加 **Save List Panel (Script)**。

**步骤 2：做背景与关闭按钮**  
**右键 → UI → Image** 做背景（可选），**右键 → UI → Button** 命名 **Btn_Close**，文字「关闭」或「返回」。

**步骤 3：做可滚动的列表（Scroll View，与按键配置面板一致：仅垂直条、仅滚轮、不可拖动）与一行预制体**  
- 在 **SaveListPanel** 下 **右键 → UI → Scroll View**。Unity 会生成 **Scroll View**，其下带 **Viewport**、**Content**、**Scrollbar Vertical**、**Scrollbar Horizontal**。  
- **与按键配置面板一致，不显示水平滚动条**：在 **Hierarchy** 里选中 **Scroll View** 下的 **Scrollbar Horizontal**，**右键 → Delete** 删掉，或取消勾选左上角禁用。只保留 **Scrollbar Vertical**。  
- **仅用滚轮、不可鼠标拖动**：选中 **Scroll View** 根物体，在 Inspector 里**移除**自带的 **Scroll Rect (Script)**，再 **Add Component** 搜索 **Scroll Rect Wheel Only**，添加 **Scroll Rect Wheel Only (Script)**。替换后新组件里的引用会清空，需要重新拖一次：
  - **Content** 格子：从 Hierarchy 里把 **Viewport** 下面的 **Content** 拖进去。
  - **Viewport** 格子：把 **Scroll View** 下面的 **Viewport** 拖进去。
  - **Vertical Scrollbar** 格子：把 **Scrollbar Vertical** 拖进去。  
  （若未在编辑器里删水平条，脚本运行时会自动隐藏 **Scrollbar Horizontal**，但建议与按键配置面板一样在编辑器里直接删掉。）  
- 把 **Scroll View** 下 **Viewport** 里的子物体命名为 **Content**（若默认已是 Content 则不用改）。选中 **Content**：添加 **Vertical Layout Group**（Spacing 约 5）；添加 **Content Size Fitter**，**Vertical Fit** 选 **Preferred Size**。  
- **一行预制体**：在 **Content** 下 **右键 → UI → Button**，命名 **Row**。创建 Button 时自带子物体 **Text**，**不要删掉**：脚本会通过 **GetComponentInChildren&lt;Text&gt;()** 把该行文字设为「玩家名 + 关卡 X」。将该 **Row** 拖到 **Resources/UI/** 下做成预制体（如 **SaveListRow**），然后删掉 Content 下该实例（或设为 inactive）。  
- 在 **SaveListPanel** 的 Inspector：**Row Prefab** 拖成 **SaveListRow**，**Content Root** 拖成上述 **Content**（留空则脚本会自动 Find("Content")）。

**步骤 4：做成预制体**  
选中 **SaveListPanel**（整棵），拖到 **Resources/UI/** 下，名字改为 **SaveListPanel**。删掉场景里这棵。

运行后脚本会 **GetAllSaveEntries()**，在 **Content** 下动态实例化 Row，每行显示玩家名与关卡，点击即加载该存档并显示 LoadingPanel。
