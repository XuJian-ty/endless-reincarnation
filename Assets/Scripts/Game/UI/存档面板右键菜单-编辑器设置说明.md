# 存档选择面板 · 右键菜单 — 编辑器里怎么做

以下在 **Unity 编辑器** 里完成，针对 **SaveListPanel** 预制体（或带 `SaveListPanel` 脚本的根物体）。

---

## 一、你的项目里已经有的

预制体 **`Assets/Resources/UI/SaveListPanel.prefab`** 里已经包含右键菜单的完整结构，并且已做这些修正：

- **SaveContextMenuPanel**：铺满全屏（Anchor 拉伸），用于盖住整个面板。
- **Blocker**：带透明 Image、勾选 Raycast Target，用于“点击菜单外关闭”。
- **MenuBody**：小面板，下面有 **Btn_Reset**、**Btn_Delete**。

**一般不需要再在编辑器里新建任何东西**，只要运行游戏，在存档列表里**右键某一项**就会弹出菜单；点“重置”/“删除”或点菜单外即可关闭。

---

## 二、若要从零在编辑器里做一遍（或自己做一个面板）

在 **SaveListPanel** 的**根物体**（挂有 `SaveListPanel.cs` 的那个）下按下面做。

### 1. 新建右键菜单根节点

1. 在 Hierarchy 里选中 **SaveListPanel** 根节点。
2. 右键 → **UI** → **Empty**（或右键 → **Create Empty**），命名为：**`SaveContextMenuPanel`**（名字必须一致，脚本用 `Find("SaveContextMenuPanel")`）。
3. 选中 **SaveContextMenuPanel**，在 Inspector 的 **Rect Transform** 里：
   - **Anchor**：点左上角小方框，选 **Stretch - Stretch**（左右上下都拉伸）。
   - **Left / Right / Top / Bottom** 全设为 **0**。  
   这样菜单层会盖住整个存档面板。

### 2. 做“点击空白关闭”的 Blocker

1. 在 **SaveContextMenuPanel** 上右键 → **UI** → **Image**，命名为：**`Blocker`**。
2. 选中 **Blocker**：
   - **Rect Transform**：Anchor 选 **Stretch - Stretch**，Left/Right/Top/Bottom 全为 **0**。
   - **Image**：  
     - **Color** 设成接近透明（例如 A=1~10），或保留默认。  
     - **Raycast Target** 必须勾选，否则点空白关不了菜单。
3. 不要给 Blocker 挂 Button；脚本会在运行时加 **EventTrigger**（PointerDown 关闭）。

**注意**：Blocker 必须是 **SaveContextMenuPanel** 的**第一个子物体**（在 Hierarchy 里排在 MenuBody 上面），这样先画 Blocker 再画菜单，点击时才能正确区分“点中菜单”和“点中空白”。

### 3. 做菜单小面板（MenuBody）

1. 在 **SaveContextMenuPanel** 上右键 → **UI** → **Image**（或 Empty），命名为：**`MenuBody`**。
2. 选中 **MenuBody**：
   - **Rect Transform**：  
     - Anchor 选 **Middle Center**；  
     - Width / Height 自定（例如 200×100）；  
     - Pos 可先 (0,0)，运行时脚本会改成鼠标位置。
   - 若用 Image：选一张图或纯色当背景，**Raycast Target** 勾选，避免点击穿透。

### 4. 在 MenuBody 下做两个按钮

1. 在 **MenuBody** 上右键 → **UI** → **Button - TextMeshPro**（或 **Button**），命名为：**`Btn_Reset`**。
   - 在 **Btn_Reset** 的 **Text** 子物体里把文案改成 **「重置」**。
2. 再在 **MenuBody** 下创建一个 Button，命名为：**`Btn_Delete`**。
   - 把文案改成 **「删除」**。
3. 两个按钮的 **On Click()** 都**不要**在 Inspector 里绑定；脚本会在运行时用 `Find("MenuBody/Btn_Reset")`、`Find("MenuBody/Btn_Delete")` 拿到 Button 并注册点击。

### 5. 层级与名字检查

最终层级应为（名字必须一致）：

```
SaveListPanel（根，挂 SaveListPanel.cs）
├─ Bg
├─ ScrollView
│   └─ …
├─ SaveContextMenuPanel
│   ├─ Blocker          ← 第一个子物体，带 Image，Raycast Target 勾选
│   └─ MenuBody
│       ├─ Btn_Reset    ← Button，文案「重置」
│       └─ Btn_Delete   ← Button，文案「删除」
└─ …
```

保存预制体（若是在预制体上改的），运行后进存档选择面板，**右键某一存档项**即可弹出菜单。

---

## 三、只改样式（不改结构）

- **菜单背景**：选中 **MenuBody**，改 Image 的 Sprite/Color。
- **按钮样式**：选中 **Btn_Reset** / **Btn_Delete**，改 Image、字体、字号等。
- **Blocker 半透明遮罩**：选中 **Blocker**，改 Image 的 Color（例如深色 + 一定透明度）。

只要保持 **SaveContextMenuPanel / Blocker / MenuBody / Btn_Reset / Btn_Delete** 的名字和层级不变，脚本都会正常找到并工作。
