# 背包面板：编辑器里一步一步怎么做（接 UIManager + 同一 Canvas）

背包面板使用项目已有的 **UIManager** 和 **BasePanel**，和主菜单、设置等**共用一个 Canvas**，只是挂在 Canvas 的不同层（Bot / Mid / Top / System）下。按下面步骤在编辑器里做完后，**按 C 键**会通过新输入系统 + 事件层打开/关闭背包（无需在玩家上写 UI 逻辑）；也可用代码 **UIManager.ShowPanel&lt;BackpackPanel&gt;("BackpackPanel", E_UI_Layer.Mid)** / **HidePanel("BackpackPanel")** 控制。

---

## 〇、可以所有面板都放在同一个 Canvas 下吗？

**可以。** 项目里的 **UIManager** 会加载一个 **Canvas** 预制体，并在其下建好 **Bot、Mid、Top、System** 四个子节点（层级）。每次 **ShowPanel** 时，会把对应面板预制体实例化并挂到指定层（如 Mid）下。所以主菜单、设置、背包、暂停等**都挂在同一个 Canvas 下**，只是父节点不同（Bot/Mid/Top/System），通过层级控制谁在上谁在下。

---

## 一、确认 Canvas 与 EventSystem 的路径（UIManager 要能加载到）

1. **UIManager** 在首次被访问时，会通过 **ResMgr.Load** 加载：
   - **"UI/Canvas"** → 即 **Resources/UI/Canvas**（预制体）
   - **"UI/EventSystem"** → 即 **Resources/UI/EventSystem**（预制体）
2. 你当前预制体在 **Resources/Prefabs/UI/Canvas** 和 **Resources/Prefabs/UI/EventSystem**，有两种做法任选其一：
   - **做法 A（推荐）**：在 **Project** 里把 **Canvas** 和 **EventSystem** 从 `Resources/Prefabs/UI/` **复制**到 **Resources/UI/**（若没有 `Resources/UI` 文件夹，先在 Resources 下建一个 **UI** 文件夹再拖进去）。这样不用改代码，UIManager 的 `"UI/Canvas"` 和 `"UI/EventSystem"` 就能加载到。
   - **做法 B**：不改资源位置，改代码。打开 **Assets/Scripts/ProjectBase/UI/UIManager.cs**，在构造函数里把：
     - `ResMgr.GetInstance().Load<GameObject>("UI/Canvas")` 改为 `ResMgr.GetInstance().Load<GameObject>("Prefabs/UI/Canvas")`
     - `ResMgr.GetInstance().Load<GameObject>("UI/EventSystem")` 改为 `ResMgr.GetInstance().Load<GameObject>("Prefabs/UI/EventSystem")`
3. **确认 Canvas 预制体结构**：打开 **Canvas** 预制体（或从 Hierarchy 里拖出来的实例），看其下是否有 **四个子物体**，名字分别为 **Bot、Mid、Top、System**（顺序无所谓）。若没有，在 Canvas 下新建四个空物体，命名为 Bot、Mid、Top、System；UIManager 会在这四个节点下挂面板。保存预制体。

## 二、做背包面板的界面结构（在场景里先搭好）

背包面板**左侧**为玩家模型区、12 项属性、当前装备武器格；**右侧**为 50 格滚动视图（每行 5 格），支持鼠标滚轮垂直滚动与 6 种排序。下面在**当前场景**里临时搭好，再拖成预制体放到 **Resources/UI/**。

**命名约定（必须一致，否则脚本 Find 回退会找不到）：**

| 节点 | 名字 | 说明 |
|------|------|------|
| 左侧根 | **LeftPanel** | 空物体，下挂左侧所有内容 |
| 右侧根 | **RightPanel** | 空物体，下挂 ScrollView、SortDropdown |
| 玩家模型区 | **PlayerModelArea** | 可选；Inspector 里可绑到脚本 |
| 12 项属性容器 | **StatsRoot** | 一排两个、共 6 排；子物体顺序见下方「StatsRoot 顺序」 |
| 装备武器格 | **EquippedWeaponIcon** | Image，正方形 |
| 滚动视图 | **ScrollView** | Unity 创建 Scroll View 后重命名为 ScrollView（保留其下 **Viewport**、**Content** 默认名） |
| 50 格父物体 | **Content** | 位于 ScrollView/Viewport/Content，不可改名（Unity 默认即 Content） |
| 每个格子 | **Slot0**～**Slot49** | 仅顺序重要；建议命名便于辨认 |
| 格子内背景 | **Background** | 每格下**第一个** Image，用于默认/品质背景；**不需在预制体里设图**，打开背包时脚本用配置里的默认图初始化 |
| 格子内图标 | **Icon** | 每格下**第二个** Image，显示物品图标（在背景之上） |
| 格子内数量 | **Count** | 每格下第一个 Text 作为数量（建议命名 Count） |
| 排序下拉 | **SortDropdown** | Dropdown |
| 悬停提示 | **TooltipPanel** | 放在 RightPanel 下；脚本未绑定时按此名 Find |
| 右键菜单 | **ContextMenuPanel** | 放在 RightPanel 下；脚本未绑定时按此名 Find |
| 装备按钮 | **Btn_Equip** | 须在 ContextMenuPanel 下 |
| 出售按钮 | **Btn_Sell** | 须在 ContextMenuPanel 下 |

**层级结构（仅写名字，便于对照）：**

```
BackpackPanel
├── LeftPanel
│   ├── PlayerModelArea（可选）
│   ├── StatsRoot（下挂 12 个带 Text 的子节点，一排两个共 6 排，顺序见下）
│   └── EquippedWeaponIcon
└── RightPanel
    ├── ScrollView（Unity Scroll View）
    │   └── Viewport
    │       └── Content（50 格父物体，Grid 5 列）
    │           ├── Slot0（Background + Icon + Count）
    │           ├── Slot1 … Slot49
    ├── SortDropdown
    ├── TooltipPanel
    └── ContextMenuPanel（Btn_Equip, Btn_Sell）
```

**StatsRoot 子物体顺序（必须一致，脚本按 GetChild(0)～(11) 取 Text）：**  
第 1 排：**生命**、**法力**  
第 2 排：**攻击**、**防御**  
第 3 排：**生命回复**、**法力回复**  
第 4 排：**暴击率**、**暴击伤害**  
第 5 排：**攻速**、**移速**  
第 6 排：**吸血**、**增伤**

**怎么做一排两个、共 6 排：** 选中 **StatsRoot** → Add Component → **Grid Layout Group** → Constraint 选 **Fixed Column Count = 2**。子物体在 Hierarchy 里的**从上到下顺序**即显示顺序（第 1 个、第 2 个为第一排左、右，第 3、4 个为第二排……）。若顺序错了，在 Hierarchy 里**拖拽**这 12 个子物体调整顺序，使自上而下为：生命、法力、攻击、防御、生命回复、法力回复、暴击率、暴击伤害、攻速、移速、吸血、增伤。

1. **建背包根节点**
   - 在 **Canvas** 的 **Mid** 下 **右键 → Create Empty**，命名为 **BackpackPanel**。
   - 选中 **BackpackPanel**，**Add Component** 搜索 **Backpack Panel**，挂上。RectTransform 可 Stretch 铺满或居中固定宽高。

2. **左侧区域**
   - 在 **BackpackPanel** 下 **右键 → Create Empty**，命名为 **LeftPanel**，摆到左侧（Anchor 左中，设好宽高）。
   - 在 **LeftPanel** 下 **Create Empty** 命名为 **PlayerModelArea**（可选）。在 **LeftPanel** 下 **Create Empty** 命名为 **StatsRoot**，**Add Component → Grid Layout Group**：Constraint 选 **Fixed Column Count = 2**（一排两个，共 6 排）。其下 12 个子节点（各带 Text），**顺序必须为**：生命、法力、攻击、防御、生命回复、法力回复、暴击率、暴击伤害、攻速、移速、吸血、增伤。在 **LeftPanel** 下 **UI → Image** 命名为 **EquippedWeaponIcon**，做成正方形格子，Source Image 留空。

3. **右侧区域**
   - 在 **BackpackPanel** 下 **右键 → Create Empty** 命名为 **RightPanel**，摆到右侧。在 **RightPanel** 下 **右键 → UI → Scroll View**，将生成的根物体重命名为 **ScrollView**（保留其下 **Viewport**、**Content** 默认名）。删掉水平 Scrollbar，Scroll Rect 只勾选 **Vertical**。
   - 选中 **Content**（RightPanel/ScrollView/Viewport/Content），**Add Component → Grid Layout Group**：Cell Size 80×80，Spacing 8×8，Constraint **Fixed Column Count = 5**。再 **Add Component → Content Size Fitter**，Vertical Fit = **Preferred Size**。
   - 在 **Content** 下做 50 个子物体，命名为 **Slot0**～**Slot49**：先建 **Slot0**（Empty），Slot0 下**先** **UI → Image** 命名为 **Background**（铺满父物体，**Source Image 留空**，打开背包时脚本会用「格子背景配置」里的默认图初始化），**再** **UI → Image** 命名为 **Icon**（铺满父物体，Source Image 留空，运行时显示物品图标），**再** **UI → Text** 命名为 **Count**（右下角，字体 14）。复制 Slot0 共 49 次得 Slot1～Slot49。脚本按**子物体顺序**取：第一个 Image = 背景，第二个 Image = 图标。Inspector 里把 **Slots Root** 拖成这个 **Content**。
   - 在 **RightPanel** 下 **右键 → UI → Dropdown** 命名为 **SortDropdown**。脚本会在 OnEnable 时自动填入 6 个排序选项。

4. **悬停与右键菜单**
   - 在 **RightPanel** 下 **Create Empty** 命名为 **TooltipPanel**（加 Image，下挂一个 Text），默认取消勾选 Active。
   - 在 **RightPanel** 下 **Create Empty** 命名为 **ContextMenuPanel**（加 Image，下挂两个 Button，分别命名为 **Btn_Equip**、**Btn_Sell**），默认取消勾选 Active。

5. **脚本引用（Inspector 中拖拽）**
   - **Slots Root**：拖成 **RightPanel/ScrollView/Viewport/Content**（50 格的父物体）。
   - **Scroll Rect**：拖成 **RightPanel/ScrollView**（带 Scroll Rect 组件的物体）。
   - **Stats Root**：拖成 **LeftPanel/StatsRoot**。
   - **Equipped Weapon Icon**：拖成 **LeftPanel/EquippedWeaponIcon**。
   - **Sort Dropdown**：拖成 **RightPanel/SortDropdown**。
   - **格子背景**：不在面板上绑定。在 **Resources/配置/** 下 **右键 → Create → 游戏/配置/格子背景配置**，新建一个配置资源，命名为 **格子背景配置**；在配置里填好 **Default Background**（空格子）、**Common / Rare / Epic / Legendary Background**（四种品质）共 5 张 Sprite。背包面板打开时通过 **ConfigManager** 按需加载该配置，有物品时按品质切换背景，空格子用默认背景。
   - **Tooltip Panel**、**Tooltip Text** 拖成 **RightPanel/TooltipPanel** 及其子 Text；**Context Menu Panel**、**Btn Equip**、**Btn Sell** 拖成 **RightPanel/ContextMenuPanel** 及其下按钮；**Player Model Area** 可选，拖成 **LeftPanel/PlayerModelArea**。

## 三、编辑器里要做的事（清单）

**需要给格子设默认背景吗？不需要。** 打开背包时脚本会从「格子背景配置」加载并给每个格子的 Background 设图：空格子用配置里的 **Default Background**，有物品的格子按品质用对应图。预制体里每个 Slot 的 **Background** 的 **Source Image 留空**即可。

**按顺序做即可：**

1. **格子结构（若还没做）**  
   - 每个 Slot 下顺序：**Background**（UI → Image）→ **Icon**（UI → Image）→ **Count**（Text）。  
   - **Background**、**Icon** 的 RectTransform 铺满父物体，**Source Image 都留空**；**Count** 放右下角。脚本会在打开背包时用配置初始化背景，运行时再刷物品图标。

2. **新建格子背景配置**  
   - 在 **Project → Resources/配置/** 下 **右键 → Create → 游戏/配置/格子背景配置**。  
   - 将生成的资源**重命名为** **格子背景配置**（ConfigManager 会按这个名字加载）。  
   - 选中该配置，在 Inspector 里填 5 张 Sprite：  
     - **Default Background**：空格子用的默认图（脚本打开背包时会赋给所有格子的 Background）。  
     - **Common / Rare / Epic / Legendary Background**：普通、精良、史诗、传说四档品质的格子背景图。

3. **其他引用**  
   - BackpackPanel 上 **Slots Root**、**Scroll Rect**、**Stats Root**、**Equipped Weapon Icon**、**Sort Dropdown**、Tooltip、ContextMenu 等按第二节绑好即可；**不需要**在面板上再绑任何格子背景图。

4. **物品显示配置**  
   - 打开 **物品显示配置**，给仙露设品质 **传说**，回血/回蓝药剂设 **精良**。

做完后：打开背包时脚本用配置里的 Default Background 初始化所有格子背景，有物品时再按品质切换。

## 四、把 BackpackPanel 做成预制体并放到 Resources/UI/

1. 在 **Project** 里确认有 **Resources/UI** 文件夹（若没有：在 **Resources** 下右键 Create → Folder，命名为 **UI**）。
2. 在 **Hierarchy** 里选中 **BackpackPanel**（带 LeftPanel、RightPanel、TooltipPanel、ContextMenuPanel 等一整棵），**拖到 Project 的 Resources/UI/** 文件夹里，松开后生成预制体 **BackpackPanel**。
3. **重要**：UIManager 加载面板用的是 **"UI/" + 面板名**，即 **Resources/UI/BackpackPanel**（预制体名须为 **BackpackPanel**）。若你拖进去后名字带了后缀，请重命名为 **BackpackPanel**。
4. 场景里刚才拖走的那棵 BackpackPanel 可以**删掉**（之后运行时会由 UIManager 从预制体实例化到 Canvas/Mid 下）。

## 五、按 C 打开背包：新输入系统 + 解耦（编辑器必做）

项目**全部使用新输入系统**，且 **UI 与玩家解耦**：按 C 由「输入事件层」发事件，「UI 桥接层」订阅后调 UIManager，**不在 PlayerController 里写 UI 逻辑**。

1. **PlayerInputActions 里已有 UI 按键**
   - 打开 **Project → Assets/Input/PlayerInputActions**，在 **Gameplay** Action Map 下应有：
     - **ToggleBackpack**（Button）→ **&lt;Keyboard&gt;/c**（背包）
     - **ToggleSkillTree**（Button）→ **&lt;Keyboard&gt;/v**（技能树）
     - **ToggleKeyConfig**（Button）→ **&lt;Keyboard&gt;/x**（按键配置）
     - **ToggleMenu**（Button）→ **&lt;Keyboard&gt;/escape**（菜单）
   - 若缺少某个，在 Gameplay 里新建对应 Action（Button），在 Bindings 里绑定上述按键即可。

2. **场景里添加「输入 + UI 桥接」物体**
   - 在 **Hierarchy** 里 **右键 → Create Empty**，命名为 **GameplayInput**（或任意名）。
   - 选中该物体，**Add Component** 添加 **GameplayInputEvents**（`Game.Input.GameplayInputEvents`）。
   - 在 Inspector 的 **Input Action Asset** 里，从 Project 把 **PlayerInputActions**（即 `Assets/Input/PlayerInputActions`）拖进去。
   - 同一物体上 **Add Component** 再添加 **GameplayUIInputBridge**（`Game.UI.GameplayUIInputBridge`），无需拖拽任何引用。
   - 保存场景。这样：按 **C/X/V/Esc** 时新输入系统触发对应 Action → **GameplayInputEvents** 发出静态事件 → **GameplayUIInputBridge** 统一订阅并调 UIManager 显示/隐藏背包、技能树、按键配置、菜单面板；玩家模块不依赖 UI，UI 按键统一由桥接管理。

3. **技能树 / 按键配置 / 菜单面板**
   - 代码已写好：按 **V** 切换 **SkillTreePanel**，按 **X** 切换 **KeyConfigPanel**，按 **Esc** 切换 **MenuPanel**，均由 **GameplayUIInputBridge** 统一处理。
   - 你只需在 **Resources/UI/** 下新建三个面板预制体，命名为 **SkillTreePanel**、**KeyConfigPanel**、**MenuPanel**，分别挂上 **SkillTreePanel**、**KeyConfigPanel**、**MenuPanel** 脚本；每个面板里若有关闭按钮，子物体命名为 **Btn_Close** 即可（基类会调 **HidePanel**）。

4. **若用代码打开/关闭背包**（例如主菜单、任务完成弹窗等）
   - **打开**：`UIManager.GetInstance().ShowPanel<BackpackPanel>("BackpackPanel", E_UI_Layer.Mid);`  
   - **关闭**：`UIManager.GetInstance().HidePanel("BackpackPanel");`  
   - 可选回调：`ShowPanel<BackpackPanel>("BackpackPanel", E_UI_Layer.Mid, panel => { /* 初始化 */ });`

## 六、配置资源（图标、品质与格子背景）

脚本通过 **ConfigManager** 读配置，请确认：

- **武器库**、**物品显示配置**、**商店价格** 在 **Resources/配置/** 下。  
- **物品显示配置**（ItemDisplayDatabaseSO）：为 **potion_hp**、**potion_mp**、**nectar** 等配好**图标**、**显示名**、**说明**；并设置**品质**（用于背包格子背景）：**仙露 = 传说**，**回血药剂 / 回蓝药剂 = 精良**，其余可按需设普通/精良/史诗/传说。  
- **武器库**：每条武器条目填好 **Display Name**、**Icon** 即可；**武器品质由掉落/生成时的实例决定**（普通/精良/史诗/传说四种都有），不需要在武器库配置里再填品质或格子背景。  
- **格子背景图**：在 **Resources/配置/** 下创建 **格子背景配置**（SlotBackgroundConfigSO）资源，命名为 **格子背景配置**，在其内填好 5 张 Sprite：**Default Background**（空格子）、**Common / Rare / Epic / Legendary Background**（四种品质）。背包打开时 ConfigManager 按需加载；物品/武器放入格子后脚本按品质切换背景，空格子用默认背景。

## 七、测试清单

1. 运行游戏，从主菜单**新游戏**进关（保证有 Player 和 Run）。
2. 按 **C**（新输入系统 ToggleBackpack），背包应出现在 **同一 Canvas** 的 **Mid** 层上：左侧为玩家属性（12 项）、装备武器格；右侧为 **50 格**（每行 5 格）滚动视图，可通过**鼠标滚轮**垂直滚动，排序下拉可选 6 种方式。按 **V/X/Esc** 会分别打开技能树、按键配置、菜单面板（需在 Resources/UI/ 下放好对应预制体并挂好对应脚本）。
3. 打精英掉武器/药剂后，再开背包，对应格有图标和数量。
4. 鼠标**悬停**有内容的格子 → TooltipPanel 出现并显示信息。
5. **右键**有内容的格子 → ContextMenuPanel 出现；武器格有【装备】【出售】，物品格只有【出售】；点【装备】/【出售】后菜单关闭，出售后格子前移。
6. 再按 C（或你写的关闭逻辑）→ **HidePanel("BackpackPanel")**，背包关闭。

按以上步骤，所有面板（含背包）都会在**同一个 Canvas** 下，由 UIManager 按层管理；背包面板本身继承 **BasePanel**，用 **ShowPanel/HidePanel** 和 **OnClick** 与现有 UI 管理器一致。
