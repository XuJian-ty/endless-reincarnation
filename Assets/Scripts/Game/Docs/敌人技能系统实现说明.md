# 敌人技能系统实现说明

## 核心结构

- `EnemyArchetypeSO`
  - 负责敌人行为配置、感知参数、巡逻参数、技能槽列表。
  - 新增敌人时，优先填写 `enemyId` 与 `skillSlots`。
- `SharedSkillDatabaseSO`
  - 现在统一叫 `技能库`。
  - 玩家与敌人共用技能定义；每个技能按 `skillId` 唯一引用。
  - 技能数据已经拆成 5 套独立事件列表：`damageEvents / physicsEvents / attributeEvents / vfxEvents / sfxEvents`。
- `CharacterAnimationLibrarySO`
  - 人物动画库。
  - 按角色分组存放动画 ID 与动画片段，技能编辑器直接拖库并选分组使用。
- `EnemyController`
  - 负责敌人运行时状态。
  - 包含生命、攻击、防御、移速、技能冷却、当前施法、临时属性修饰。
- `EnemyCombat`
  - 负责技能执行。
  - 施法开始时触发动画，随后按时间轴执行事件、效果、表现。
- `BehaviorTree`
  - 决策层只关心“放哪个技能槽”。
  - 推荐节点：`CondCanCastSkill(slot)`、`CondIsInSkillRange(slot)`、`ActionSetIntentCastSkill(slot)`。

## 技能数据模型

一个技能由以下部分组成：

- `skillId`
  - 技能唯一 ID。
- `ignoreAnimationDamageEvents`
  - 兼容字段，当前技能效果统一由时间轴驱动。
- `damageEvents / physicsEvents / attributeEvents / vfxEvents / sfxEvents`
  - 技能时间轴的 5 套独立事件列表。

每个事件可配置：

- `startTime`
  - 开始时间。
- `triggerMode`
  - `Once` 或 `Repeated`。
- `activeDuration`
  - 重复事件的持续触发窗口。
- `repeatInterval`
  - 重复触发间隔。

其中：

- `damageEvents`
  - 事件内部配置 `damageEffects`。
  - 每条伤害效果直接内嵌检测方式、形状、范围、层级、命中停顿、检测时长。
  - `检测时长` 表示每次伤害触发后判定持续存在的时间窗口；同一目标在同一检测窗口内只会在第一次进入时命中一次。
  - 命中后还可单独触发：命中物理、命中属性、命中特效、命中音效。
- `physicsEvents`
  - 顶层物理事件，仅处理自身位移 / 腾空。
- `attributeEvents`
  - 顶层属性事件，仅处理自身回血、回蓝、Buff / Debuff。
- `vfxEvents`
  - 顶层特效事件。
- `sfxEvents`
  - 顶层音效事件。

## 当前已支持的效果类型与职责

- 顶层独立触发：
  - `物理事件`
    - `位移`
    - `腾空`
  - `属性事件`
    - 回复生命、回复法力、增减属性、吸血、增伤、减伤等
  - `特效事件`
  - `音效事件`
- 命中后触发：
  - `伤害效果`
    - 负责命中盒 / 射线 / 碰撞检测与伤害结算
  - `命中物理效果`
    - `击退`
    - `拉拽`
    - `击飞`
    - `眩晕`
      - 统一走玩家/敌人的硬控入口，同时附带停移动控制
  - `命中属性效果`
  - `命中特效效果`
  - `命中音效效果`

## 当前已支持的目标选择

- `Self`
- `DetectedTargets`

## 检测与效果的职责划分

- 检测不是效果。
- 检测统一走 `DamageDetectionRunner`。
- 伤害检测参数已经内嵌到技能库的 `SkillDamageEffect` 中，不再依赖外部伤害配置库。
- 效果只关心“拿到目标后做什么”。

这意味着：

- 想改碰撞/范围/射线的几何参数，直接改技能库里对应 `damageEffect` 的内嵌字段。
- 想改技能在什么时候伤害、什么时候位移、什么时候加 Buff，改 `技能库` 中对应技能的 5 类事件列表。

## 扩展方式

### 新增敌人

1. 在敌人属性库里加一条 `enemyId`。
2. 在敌人行为配置库里加一条 `EnemyArchetypeSO`。
3. 给 `skillSlots` 配技能。
4. 给敌人挂行为树，或复用默认行为树。

### 新增技能

1. 在 `技能库` 中加一条技能定义。
2. 配对应的 5 类事件列表。
3. 如需预览动画，在 `人物动画库` 中配好该角色分组的动画 ID 与动画片段。
4. 在敌人的 `skillSlots` 或玩家技能配置中引用该 `skillId`。

### 新增技能效果类型

当前需要改代码：

1. 给对应的事件或效果数据结构增加新字段。
2. 在 `SkillEffectExecutor` 中增加对应处理分支。

这属于“新增机制”，不是“新增技能组合”。

## 当前建议

- 敌人配置只用 `enemyId + skillSlots + 技能库`。
- 行为树节点只用 `CondCanCastSkill / CondIsInSkillRange / ActionSetIntentCastSkill`。
- 新 Boss / 精英技能优先使用 5 类独立事件，不再依赖外部伤害配置库。
- 旧动画事件伤害链已停用，伤害、物理、属性、特效、音效统一从技能时间轴执行。
