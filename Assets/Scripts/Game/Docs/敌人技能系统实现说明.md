# 敌人技能系统实现说明

## 核心结构

- `EnemyArchetypeSO`
  - 负责敌人行为配置、感知参数、巡逻参数、技能槽列表。
  - 新增敌人时，优先填写 `enemyId` 与 `skillSlots`。
- `EnemySkillDatabaseSO`
  - 负责技能定义。
  - 每个技能是一条数据，包含动画触发器、冷却、施法时长、时间轴事件。
- `EnemyController`
  - 负责敌人运行时状态。
  - 包含生命、攻击、防御、移速、技能冷却、当前施法、临时属性修饰。
- `EnemyCombat`
  - 负责技能执行。
  - 施法开始时触发动画，随后按时间轴执行事件、效果、表现。
- `BehaviorTree`
  - 决策层只关心“放哪个技能槽”。
  - 推荐节点：`CondCanCastSkill(slot)`、`CondIsInSkillRange(slot)`、`ActionSetIntentCastSkill(slot)`。

## 技能数据模型

一个技能由以下部分组成：

- `animationTrigger`
  - 触发的 Animator Trigger，例如 `MeleeAttack`、`RangedAttack`、`CastSkill0`。
- `cooldown`
  - 技能冷却。
- `castDuration`
  - 本次施法持续多久，AI 会在这段时间内视为忙碌。
- `events`
  - 技能时间轴事件列表。

每个事件可配置：

- `startTime`
  - 开始时间。
- `triggerMode`
  - `Once` 或 `Repeated`。
- `activeDuration`
  - 重复事件的持续窗口。
- `repeatInterval`
  - 重复触发间隔。
- `detectorDamageName`
  - 复用 `AnimationFrameDamageDatabaseSO` 的检测定义。
- `effects`
  - 效果列表。
- `cues`
  - 表现事件列表，复用 `AnimationFrameVfxDatabaseSO`。

## 当前已支持的效果类型

- `Damage`
  - 对目标造成伤害。
- `Heal`
  - 回复生命，可按最大生命百分比。
- `ApplyStatModifier`
  - 临时加攻、防、移速等。
- `Knockback`
  - 将目标沿方向推出。
- `Pull`
  - 将目标沿方向拉近。
- `DisplaceSelf`
  - 敌人自身位移。

## 当前已支持的目标选择

- `Self`
- `CurrentTarget`
- `DetectedTargets`

## 检测与效果的职责划分

- 检测不是效果。
- 检测统一走 `DamageDetectionRunner`。
- 效果只关心“拿到目标后做什么”。

这意味着：

- 想改碰撞/范围/射线的几何参数，改 `AnimationFrameDamageDatabaseSO`。
- 想改技能在什么时候伤害、什么时候位移、什么时候加 Buff，改 `EnemySkillDatabaseSO`。

## 扩展方式

### 新增敌人

1. 在敌人属性库里加一条 `enemyId`。
2. 在敌人行为配置库里加一条 `EnemyArchetypeSO`。
3. 给 `skillSlots` 配技能。
4. 给敌人挂行为树，或复用默认行为树。

### 新增技能

1. 在 `EnemySkillDatabaseSO` 中加一条技能定义。
2. 配动画触发器、冷却、施法时长。
3. 配时间轴事件。
4. 在敌人的 `skillSlots` 中引用该 `skillId`。

### 新增技能效果类型

当前需要改代码：

1. 给 `EnemySkillEffectType` 增加一个枚举值。
2. 在 `EnemyCombat.ExecuteEffect` 中增加对应处理分支。

这属于“新增机制”，不是“新增技能组合”。

## 当前建议

- 敌人配置只用 `enemyId + skillSlots + EnemySkillDatabaseSO`。
- 行为树节点只用 `CondCanCastSkill / CondIsInSkillRange / ActionSetIntentCastSkill`。
- 新 Boss / 精英技能尽量使用时间轴事件，不再依赖动画里的 `OnDealDamage` 字符串事件。
