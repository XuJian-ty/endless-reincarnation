# 动作系统需求（完整版）

> 包含：所有状态、状态间切换逻辑、预输入规则、输入→动作映射、策略表、特殊规则。

---

## 一、输入与动作映射

### 1.1 输入源（PlayerInputData）

| 输入 | 类型 | 说明 |
|------|------|------|
| MoveInput | Vector2 | WASD/摇杆，持续 |
| LookDelta | Vector2 | 鼠标/右摇杆，持续 |
| IsRunRequested | bool | 双击检测结果（0.25s 内第二次按下移动） |
| IsLmbHeld | bool | LMB 当前是否按住（Hold performed/canceled 维护） |
| JumpPressed | bool | 单帧，Space |
| DodgePressed | bool | 单帧，Shift |
| AttackTapPressed | bool | 单帧，LMB Tap（≤0.2s 松开） |
| ChargeStartPressed | bool | 单帧，LMB Hold 达 0.2s |
| ChargeReleasePressed | bool | 单帧，LMB SlowTap 达 0.7s 后松开 |
| AltAttackPressed | bool | 单帧，RMB（下落攻击） |
| Skill0Pressed～Skill3Pressed | bool | 单帧，数字键1/2/3/4 |

### 1.2 动作枚举（GameAction）

| 动作 | 触发条件 | 备注 |
|------|----------|------|
| None | — | 空 |
| Walk | MoveInput 有值 且 非 IsRunRequested | 单击 WASD |
| Run | MoveInput 有值 且 IsRunRequested | 双击 WASD |
| Jump | JumpPressed | 单段跳 |
| NormalAttack | AttackTapPressed 且 **当前为地面状态** | 地面普攻 |
| AirAttack | AttackTapPressed 且 **当前为空中状态** | 空中普攻 |
| ChargeStart | ChargeStartPressed | LMB 按住 0.2s |
| ChargeRelease | ChargeReleasePressed | LMB 0.7s 后松开 |
| FallAttack | AltAttackPressed | 空中 RMB |
| Dodge | DodgePressed | 闪避 |
| Skill | Skill0～3Pressed | 技能 0～3，SkillIndex 存 0～3 |

### 1.3 候选动作收集顺序（优先级从高到低）

状态机每帧按以下顺序收集候选动作，**先被收集的优先**；同帧只响应**第一个**得到 Interrupt 的候选。

1. Dodge  
2. Skill（0～3）  
3. ChargeRelease  
4. FallAttack  
5. ChargeStart  
6. AttackTap → 根据 **IsAirState(CurrentState)** 映射为 NormalAttack 或 AirAttack  
7. Jump  
8. MoveInput 有值 → Walk 或 Run  

**空中状态（IsAirState）**：JumpState、FallState、AirAttackState、FallAttackStartState、**FallAttackLoopState**。  
在这些状态下 AttackTap 映射为 **AirAttack**，否则为 **NormalAttack**。

## 二、预输入（Buffer）规则

### 2.1 基本规则

- **槽位**：全局只有 **1 个**预输入槽（PendingActionData）。
- **覆盖**：新写入的预输入**覆盖**旧预输入（当前实现：仅当 _pending 为空时才写入 Buffer，即只保留「第一个被 Buffer 的」候选，见代码注释）。
- **消费**：由**自然结束**的状态在结束时调用 `CompleteWithPending(fallback)`：先 `ConsumePending()`，若非空则 `ExecuteAction(pending)`，否则执行 fallback（如 GoTo\<IdleState\>）。
- **清空**：HitStunState 进入时 `ClearPending()`；DodgeState 在 80% 结束时对 Walk/Run 调用 `ConsumePending()` 并立刻执行（CompleteWithPending）。

### 2.2 谁可以写入预输入（Buffer）

仅当当前状态对某动作返回 **TransitionPolicy.Buffer** 时，该动作才会被写入 _pending。  
具体见下方「策略表」：每个状态对每个动作是 Interrupt / Buffer / Ignore 之一。

### 2.3 普攻连击特殊消费

- **TryConsumePendingNormalAttack()**：仅当 _pending.Action == NormalAttack 时消费并返回 true。
- **调用方**：AttackStateBase 在「连击窗口」内每帧检查；若返回 true 则执行 AdvanceCombo()（下一段或回 Idle）。
- **连击窗口**：当前段动画播到约 85% 时开启，持续 **0.3s**（ComboWindowDuration）；窗口内若没有缓存的 NormalAttack 则超时后 `CompleteWithPending(() => GoTo<IdleState>())`。

## 三、所有状态列表

### 3.1 地面

| 状态类 | 说明 |
|--------|------|
| IdleState | 待机，Speed=0，Locomotion Trigger |
| MoveState | 走/跑，由 InitialIsRunning 或 IsRunRequested 决定 |
| LandState | 着陆动画，结束后 CompleteWithPending → Idle |
| DodgeState | 闪避，朝面朝方向，全程无敌；80% 结束时若有 Walk/Run 缓存则进入 MoveState |
| Attack1State～Attack4State | 普攻第 1～4 段，继承 AttackStateBase |
| ChargeStartState | 蓄力开始，LMB 松开则回 Idle，动画 85% 切 ChargeLoop |
| ChargeLoopState | 蓄力循环，LMB 松开回 Idle；SlowTap 由 Interrupt 切 ChargeRelease |
| ChargeReleaseState | 蓄力释放动画，结束后 CompleteWithPending → Idle |

### 3.2 空中

| 状态类 | 说明 |
|--------|------|
| JumpState | 起跳，垂直速度≤0 切 Fall，接地切 Land |
| FallState | 下落，距地 0.3m 切 Land |
| AirAttackState | 空中普攻单段，结束后接地→Land、否则 CompleteWithPending→Fall |
| FallAttackStartState | 下落攻击开始，接地→FallAttackLand，动画 85%→FallAttackLoop |
| FallAttackLoopState | 下落攻击循环，距地 0.3m→FallAttackLand |
| FallAttackLandState | 下落攻击落地打击，结束后 CompleteWithPending→Idle |

### 3.3 共享

| 状态类 | 说明 |
|--------|------|
| Skill0State～Skill3State | 技能 0～3，继承 SkillStateBase；MP 不足直接回 Idle/Fall |
| HitStunState | 受击硬直，进入时 ClearPending，期间全部 Ignore，结束后接地→Idle 否则 Fall |

## 四、状态间切换逻辑（由状态内部 OnTick / 事件驱动）

### 4.1 地面 → 地面

| 当前状态 | 条件 | 目标状态 |
|----------|------|----------|
| IdleState | 有移动输入 | MoveState（Walk/Run Interrupt） |
| IdleState | AttackTap | Attack1State（NormalAttack Interrupt） |
| IdleState | Jump | JumpState（Interrupt） |
| IdleState | !IsGrounded | FallState |
| MoveState | 无移动输入 | IdleState |
| MoveState | !IsGrounded | FallState |
| MoveState | AttackTap / Jump | 见策略表（Interrupt） |
| LandState | AnimNearEnd() | CompleteWithPending → Idle 或执行 pending |
| DodgeState | AnimNearEnd(0.80f) | CompleteWithPending → 若 pending 为 Walk/Run 则 MoveState（InitialIsRunning 注入），否则 Idle 或执行 pending |
| Attack1～3 | 窗口内 TryConsumePendingNormalAttack | Attack2～4 |
| Attack4 | 窗口内 TryConsumePendingNormalAttack | IdleState |
| Attack1～4 | 窗口超时 | CompleteWithPending → Idle 或执行 pending |
| ChargeStartState | !input.IsLmbHeld | IdleState |
| ChargeStartState | AnimNearEnd(0.85f) | ChargeLoopState |
| ChargeLoopState | !input.IsLmbHeld | IdleState |
| ChargeReleaseState | AnimNearEnd() | CompleteWithPending → Idle 或执行 pending |

### 4.2 地面 → 空中

| 当前状态 | 条件 | 目标状态 |
|----------|------|----------|
| IdleState / MoveState / 等 | Jump Interrupt | JumpState |
| IdleState / MoveState | !IsGrounded（如落崖） | FallState |

### 4.3 空中 → 空中

| 当前状态 | 条件 | 目标状态 |
|----------|------|----------|
| JumpState | Ctx.Mover.VerticalVelocity ≤ 0 | FallState |
| JumpState | IsGrounded | LandState |
| FallState | IsNearGround(0.3f) | LandState |
| AirAttackState | AnimNearEnd() 且 IsGrounded | LandState |
| AirAttackState | AnimNearEnd() 且 !IsGrounded | CompleteWithPending → Fall 或执行 pending |
| FallAttackStartState | IsGrounded | FallAttackLandState |
| FallAttackStartState | AnimNearEnd(0.85f) | FallAttackLoopState |
| FallAttackLoopState | IsNearGround(0.3f) | FallAttackLandState |

### 4.4 空中 → 地面

| 当前状态 | 条件 | 目标状态 |
|----------|------|----------|
| JumpState / FallState | IsNearGround(0.3f) / IsGrounded | LandState |
| AirAttackState | AnimNearEnd() 且 IsGrounded | LandState |
| FallAttackStartState / LoopState | 接地或距地 0.3m | FallAttackLandState |
| FallAttackLandState | AnimNearEnd() | CompleteWithPending → Idle 或执行 pending |
| LandState | AnimNearEnd() | CompleteWithPending → Idle 或执行 pending |

### 4.5 技能 / 受击

| 当前状态 | 条件 | 目标状态 |
|----------|------|----------|
| Skill0～3（SkillStateBase） | OnEnter 时 MP 不足 | IdleState（地面）或 FallState（空中） |
| Skill0～3 | AnimNearEnd() | CompleteWithPending → Idle/Fall 或执行 pending |
| 任意（非 Dodge） | OnHit 受击 | HitStunState（ClearPending） |
| HitStunState | _timer≤0 | IdleState（接地）或 FallState（空中） |

## 五、策略表（GetPolicyFor：每个状态对每个动作的响应）

**约定**：Interrupt = 立即打断并执行该动作；Buffer = 写入预输入（若当前实现仅空槽写入则只保留第一个 Buffer）；Ignore = 丢弃。

### 5.1 基类默认（PlayerStateBase）

适用于「有自然结束点」的动作状态（如攻击、技能、蓄力），子类未覆写时使用：

| 动作 | 策略 |
|------|------|
| Dodge | Interrupt |
| Skill | Interrupt |
| ChargeStart | Interrupt |
| NormalAttack | Buffer |
| Jump | Buffer |
| Walk | Buffer |
| Run | Buffer |
| ChargeRelease, AirAttack, FallAttack | Ignore |

### 5.2 IdleState

| 动作 | 策略 | 说明 |
|------|------|------|
| Walk, Run, Jump, NormalAttack | **Interrupt** | 无自然结束点，必须立即响应 |
| 其余 | 同基类 | Dodge/Skill/ChargeStart Interrupt，其余 Ignore |

### 5.3 MoveState

| 动作 | 策略 | 说明 |
|------|------|------|
| Jump, NormalAttack | **Interrupt** | 移动中可立刻跳/攻 |
| 其余 | 同基类 | Walk/Run Buffer，Dodge/Skill/ChargeStart Interrupt |

### 5.4 DodgeState

| 动作 | 策略 | 说明 |
|------|------|------|
| Dodge | **Ignore** | 不可连续闪避 |
| 其余 | **Buffer** | 含 Walk/Run，在 80% 结束时若 pending 为 Walk/Run 则进入 MoveState |

### 5.5 Attack1～4（AttackStateBase）

| 动作 | 策略 |
|------|------|
| Dodge, Skill, ChargeStart | Interrupt（基类） |
| NormalAttack | Buffer（基类），窗口内由 TryConsumePendingNormalAttack 消费 |
| Jump, Walk, Run | Buffer（基类） |
| ChargeRelease, AirAttack, FallAttack | Ignore（基类） |

### 5.6 ChargeStartState

| 动作 | 策略 |
|------|------|
| Dodge, Skill, ChargeRelease | Interrupt |
| ChargeStart | Ignore（已在蓄力） |
| 其余 | Buffer |

### 5.7 ChargeLoopState

| 动作 | 策略 |
|------|------|
| Dodge, Skill, ChargeRelease | Interrupt |
| ChargeStart | Ignore |
| 其余 | Buffer |

### 5.8 ChargeReleaseState

继承基类默认即可（Dodge/Skill/ChargeStart Interrupt，Walk/Run/Jump/NormalAttack Buffer）。

### 5.9 LandState

继承基类默认；自然结束时 CompleteWithPending → Idle。

### 5.10 JumpState

| 动作 | 策略 |
|------|------|
| Dodge, Skill, AirAttack, FallAttack | Interrupt |
| Jump, ChargeStart, ChargeRelease, NormalAttack | Ignore（单段跳；空中不蓄力；NormalAttack 已映射为 AirAttack） |
| Walk, Run | Buffer |

### 5.11 FallState

| 动作 | 策略 |
|------|------|
| Dodge, Skill, AirAttack, FallAttack | Interrupt |
| Jump, ChargeStart, ChargeRelease, NormalAttack | Ignore |
| Walk, Run | Buffer |

### 5.12 AirAttackState

| 动作 | 策略 |
|------|------|
| Dodge, Skill, FallAttack | Interrupt |
| AirAttack, ChargeStart, ChargeRelease, NormalAttack, Jump | Ignore |
| Walk, Run | Buffer |

### 5.13 FallAttackStartState

| 动作 | 策略 |
|------|------|
| Skill | Interrupt |
| 其余 | Ignore（下落攻击期间只允许技能打断） |

### 5.14 FallAttackLoopState

| 动作 | 策略 |
|------|------|
| Skill | Interrupt |
| 其余 | Ignore |

### 5.15 FallAttackLandState

| 动作 | 策略 |
|------|------|
| Dodge, Skill, ChargeStart | Interrupt |
| NormalAttack, Jump, Walk, Run | Buffer |
| AirAttack, FallAttack, ChargeRelease | Ignore |

### 5.16 Skill0～3（SkillStateBase）

| 动作 | 策略 |
|------|------|
| Dodge, Skill | Interrupt（新技能可打断旧技能） |
| FallAttack, AirAttack | Ignore |
| 其余 | Buffer |

### 5.17 HitStunState

| 动作 | 策略 |
|------|------|
| 全部 | **Ignore** |

## 六、特殊规则汇总

1. **无自然结束点的状态**  
   IdleState、MoveState 不会调用 CompleteWithPending，因此必须对 Walk/Run/Jump/NormalAttack 设为 **Interrupt**，否则这些输入只会被 Buffer 且永远无法执行。

2. **闪避 80% 结束与缓存移动**  
   DodgeState 在 AnimNearEnd(0.80f) 时调用 CompleteWithPending；若 pending 为 Walk 或 Run，则 ConsumePending 并 GoTo\<MoveState\>(s => s.InitialIsRunning = (pending==Run))，实现「闪避结束时若有缓存走/跑则进入移动」。

3. **普攻连击窗口**  
   每段普攻在动画约 85% 时开启 0.3s 窗口；窗口内若 TryConsumePendingNormalAttack 为 true 则 AdvanceCombo（下一段或 Idle）；超时则 CompleteWithPending → Idle 或执行其他 pending。

4. **蓄力取消**  
   ChargeStartState / ChargeLoopState 下若 !input.IsLmbHeld（提前松开），直接 GoTo\<IdleState\>；ChargeRelease 由 SlowTap 触发，策略为 Interrupt，不会走到「松开回 Idle」分支。

5. **空中 AttackTap 映射**  
   当前状态属于 IsAirState 时，AttackTap 收集为 **AirAttack**，否则为 **NormalAttack**。IsAirState 需包含：JumpState、FallState、AirAttackState、FallAttackStartState、**FallAttackLoopState**。

6. **Run 与 MoveState**  
   Walk/Run 都执行 ChangeState\<MoveState\>；是否跑步由 MoveState 内 InitialIsRunning（Dodge 80% 释放缓存时注入）或每帧 input.IsRunRequested 决定。

7. **动画结束判定**  
   使用 `AnimNearEnd(threshold)`，内部带 **StateAge > 0.1s** 保护，避免刚切状态时仍读到上一段动画的 normalizedTime 导致误判。

8. **Locomotion Trigger**  
   仅 IdleState、MoveState 的 OnEnter 调用 TriggerLocomotion()，用于 Animator 的 Any State → IdleWalkRun 只响应此 Trigger，不依赖 IsGrounded 每帧条件。

## 七、执行顺序（每帧）

1. **PlayerController.Update**：ManualUpdate() → StateMachine.Tick(dt, input) → Mover.Tick(dt)。
2. **StateMachine.Tick**：先 **ProcessActions(input)**（收集候选 → 按策略 Interrupt/Buffer），再 **CurrentState.Tick(dt, input)**。
3. **ProcessActions**：对每个候选依次 GetPolicyFor；第一个 Interrupt 则 ExecuteAction 并 return；Buffer 则视实现写入 _pending（当前为仅空槽写入）。
4. 状态内 OnTick 可调用 GoTo、CompleteWithPending、TryConsumePendingNormalAttack 等，从而在同帧或后续帧完成状态切换与预输入消费。
