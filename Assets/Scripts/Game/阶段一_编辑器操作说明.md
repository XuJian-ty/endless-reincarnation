# 阶段一：编辑器里要做的事

按下面步骤在 Unity 编辑器里配置，即可跑通「进关 → 打怪 → 掉钱/经验」的最小闭环。

---

## 〇、五种敌人与控制器（必读）

- **近战小怪、远程小怪、精英、守卫者、Boss** 这 5 种敌人，**都用同一个脚本**：`EnemyController`（`Game.Presentation.EnemyController`）。
- 区别只在于**挂的配置资源不同**：
  - 每个敌人预制体上都有 **EnemyController** 组件；
  - 在 **Stats SO** 里拖入不同的 **EnemyStatsSO** 资源；
  - 在每份 EnemyStatsSO 里把 **Type** 选成对应类型（Melee Minion / Ranged Minion / Elite / Guardian / Boss），并填好该类型的血量、攻击、金币、经验等。
- 因此你要做的是：
  - **5 份 EnemyStatsSO**（如 `EnemyStats_MeleeMinion`、`EnemyStats_RangedMinion`、`EnemyStats_Elite`、`EnemyStats_Guardian`、`EnemyStats_Boss`），Type 和数值按需求各填各的；
  - **5 个敌人预制体**（或先做 1～2 种试玩），每个预制体都挂**同一个** EnemyController，只是 **Stats SO** 拖成上面对应的那一份。
- 精英/守卫者若需要掉落：在**预制体**的 EnemyController 上再拖 **Drop Table**、**Weapon Source**；小怪和 Boss 可以不拖（只掉金币或按需求书单独处理）。

---

## 一、新建 Layer「Enemy」

1. 菜单 **Edit → Project Settings → Tags and Layers**。
2. 在 **Layers** 里选一个未用的 User Layer（如 Layer 6），命名为 **Enemy**。
3. 后面所有敌人预制体/物体都要设到这个层，否则玩家攻击检测不到。

---

## 二、玩家挂上 PlayerCombat

1. 打开 **玩家预制体**（或关卡里已放置的玩家物体）。
2. 确保已有 **PlayerController**、**PlayerAnimatorController**、**PlayerInput** 等（你已有）。
3. **Add Component** 添加 **PlayerCombat**（脚本在 `Game.Presentation.PlayerCombat`）。
4. 在 Inspector 里（可选）：
   - **Origin Forward**：检测球心在角色前方的偏移，默认 0.5 即可。
   - **Radius**：检测半径，默认 1.5；武器长可调到 2。
   - **Enemy Layer Name**：填 **Enemy**（和上面建的 Layer 名一致）。
   - **Skill Multiplier**：普攻倍率，先保持 1。

保存预制体。**不用**再在代码里挂事件，PlayerCombat 会在 OnEnable 里自己订阅 Anim 的命中事件。

---

## 三、配置敌人用的 SO（5 种敌人各一份）

1. **EnemyStats（基础属性）**
   - 在 Project 窗口里 **右键 → Create → Game → Enemy → EnemyStats**（或菜单 **Assets → Create → Game → Enemy → Enemy Stats**）。
   - 取名如 `EnemyStats_MeleeMinion`；再同样方式创建 `EnemyStats_RangedMinion`、`EnemyStats_Elite`、`EnemyStats_Guardian`、`EnemyStats_Boss`（或先做 1～2 种试玩）。
   - 选中每份 SO，在 Inspector 里填写：
     - **Enemy Id**：唯一标识，如 `melee_minion_01`、`elite_01`。
     - **Display Name**：显示用名字，如「近战小怪」「精英」。
     - **Type**：下拉选 **Melee Minion / Ranged Minion / Elite / Guardian / Boss** 之一（必须和该 SO 用途一致）。
     - **Base Hp / Attack / Defense / Move Speed**：难度 1 时的基础值（如近战 60/10/5/3.8，精英可更高）。
     - **Gold Min / Gold Max**：击杀掉落金币范围（如 5～10）。
     - **Base Exp**：击杀后玩家获得的经验（如 10）。

2. **DifficultyScaling（难度系数，全关卡共用一份即可）**
   - 若还没有：**右键 → Create → Game → Balance → DifficultyScaling**。
   - 默认即可：HP/攻击/防御/移速每升 1 难度 +30%/+30%/+20%/+10%；之后可按需求改。

---

## 四、做敌人预制体并放到关卡（每一步具体操作）

**目的**：做出一个「带碰撞、挂好 EnemyController、Layer 为 Enemy」的敌人物体，做成预制体，再在关卡里摆放。

1. **新建敌人物体**
   - 在 **Hierarchy** 里 **右键 → Create Empty**。
   - 选中该物体，在 Inspector 顶部 **Layer** 下拉选 **Enemy**（若没有，先到 Edit → Project Settings → Tags and Layers 里建好 Enemy 层，见上文「一」）。
   - 在 Inspector 里把 **Name** 改成如 `Enemy_MeleeMinion`（方便区分）。

2. **挂碰撞体（让玩家攻击能检测到）**
   - 选中该物体，**Add Component** 搜索 **Capsule Collider**（或 **Box Collider**）。
   - **Radius / Height** 或 **Size** 调成能包住敌人模型的大小（先做空物体时可设 Radius≈0.5、Height≈2，后面加模型再微调）。
   - **Is Trigger** 保持**不勾选**（普通碰撞体即可，OverlapSphere 能检测到；勾选后若你后续做物理碰撞再单独调）。

3. **挂 EnemyController 并绑定 SO**
   - 同一物体上 **Add Component** 搜索 **Enemy Controller**（脚本名 `EnemyController`，命名空间 `Game.Presentation`）。
   - 在 Inspector 的 EnemyController 里：
     - **Stats SO**：从 Project 里把对应那一份 **EnemyStatsSO**（如 `EnemyStats_MeleeMinion`）拖进来；**必填**，否则敌人没有属性。
     - **Difficulty Scaling**：拖入你建好的 **DifficultyScalingSO**（全关卡共用一份）；**必填**，否则难度不生效。
     - **Drop Table**、**Weapon Source**：近战/远程小怪、Boss 可不填（只掉金币）；**精英、守卫者**若需要按表掉武器/药剂，再拖入本关的 **DropTableSO** 和一个 **WeaponSO**。

4. **可选：加一个简单模型（方便看见位置）**
   - 在 Hierarchy 里选中该敌人物体，**右键 → 3D Object → Capsule**（或 Cube）作为**子物体**。
   - 子物体只负责显示，**不用**改 Layer；碰撞体在**根物体**上即可。
   - 若用真实怪物模型：把模型拖成子物体，根物体上的 Collider 包住整只怪即可。

5. **做成预制体**
   - 在 Hierarchy 里把 `Enemy_MeleeMinion`（或你起的名字）**拖到 Project 窗口**的某个文件夹（如 `Assets/Prefabs/Enemies`）。
   - 松开后会出现一个预制体资源；原场景里的物体会变成预制体实例（蓝色）。
   - 若你做了多种敌人：对每种敌人都重复「新建 Empty → 设 Layer → 加 Collider → 加 EnemyController → 拖对应 Stats SO → 可选加模型 → 拖成预制体」，只是名字和 Stats SO 不同。

6. **在关卡里摆几个**
   - 打开你要玩的关卡场景（如 **Level_1**）。
   - 从 Project 里把刚做的**敌人预制体**拖进 **Hierarchy**（或拖到 Scene 视图里）。
   - 用移动工具把敌人放到玩家能跑过去、挥刀能碰到的位置（例如玩家出生点前方几米）。
   - 可多拖几份同一预制体，摆在不同位置，方便测试。

---

## 五、关卡里确保有难度和成长配置（LevelBootstrapper 详解）

**目的**：关卡里要有一个物体挂 **LevelBootstrapper**，用来在进关时初始化玩家、出生点、以及本关的关卡配置/难度系数/成长表。敌人里的 EnemyController 会从 **GameStateMachine.CurrentRun** 读当前难度，而 CurrentRun 是由 LevelBootstrapper 配合主菜单「新游戏/读档」填好的；同时 LevelBootstrapper 会把你拖的 **DifficultyScalingSO**、**LevelGrowthSO** 等用在合适的地方（例如敌人用难度系数、玩家用成长表）。

1. **LevelBootstrapper 是什么、放在哪**
   - **LevelBootstrapper** 是一个脚本（`Game.GameFlow.LevelBootstrapper`），挂在**关卡场景里的某一个空物体**上（通常和「关卡管理」「出生点」放一起）。
   - 若你还没有：在 **Hierarchy** 里 **右键 → Create Empty**，命名为如 `LevelSetup` 或 `LevelBootstrapper`；选中它，**Add Component** 搜索 **Level Bootstrapper**。

2. **LevelBootstrapper 上每个字段填什么**
   - **Player Controller**：拖**场景里**的玩家物体（带 PlayerController 组件的那个）。LevelBootstrapper 会在 Start 里调 `playerController.Init(playerModel)` 并订阅死亡事件，所以必须拖。
   - **Spawn Point**：拖一个**空物体**或一个点，表示玩家「新进本关」时的出生位置（读档时若有关卡快照会用存档里的位置，否则用这个点）。
   - **Level Config**：拖本关对应的 **LevelConfigSO**（Create → Game → Level → LevelConfig），用来填本关编号、守卫者数量等；敌人数量/刷怪逻辑后续阶段再用，这里可先拖一份占位。
   - **Difficulty Scaling**：拖你建好的 **DifficultyScalingSO**（和敌人用的同一份即可）；LevelBootstrapper 主要给关卡逻辑用，敌人自己也会从 GameStateMachine 读难度并用自己的 DifficultyScaling 引用。
   - **Fallback Level Growth**：拖**玩家成长表** **LevelGrowthSO**（Create → Game → Balance → LevelGrowth）。当**直接运行本关场景**（不经过主菜单）时，没有 RunData，会用这个 Fallback 建一个默认玩家；从主菜单「新游戏/读档」进关时，会用 GameStateMachine 里的 Player 和 Run，这个 Fallback 只是备用。

3. **没有这些 SO 时怎么建**
   - **LevelConfigSO**：Project 里右键 → Create → Game → Level → LevelConfig；Level Index 填 1（第一关），其它可默认。
   - **LevelGrowthSO**：右键 → Create → Game → Balance → LevelGrowth；用于玩家 1～10 级属性成长，可按需求调。
   - **DifficultyScalingSO**：上文「三」里已建；和敌人预制体上拖的是同一份即可。

4. **难度从哪里来**
   - 从主菜单**新游戏**进关时，`GameStateMachine.CurrentRun.difficulty` 为 1。
   - 玩家死亡回滚后，难度会 +1；敌人血量/攻击会按 **DifficultyScalingSO** 和当前难度放大。
   - 敌人脚本在 Start 里会取 `GameStateMachine.GetInstance().CurrentRun?.difficulty ?? 1`，所以只要关卡用 LevelBootstrapper 正常进关（或直接 Play 场景时用 Fallback），难度就会生效。

## 六、测试清单（怎么确认功能正常）

1. **运行游戏**
   - 点击 Unity 顶部 **Play**；从**主菜单**选「**新的游戏**」并选一个存档槽，进入第一关（或你摆敌人的那一关）。

2. **确认玩家能打中敌人**
   - 操作角色走到敌人旁边，用**地面普攻**（左键短按）、**蓄力**（长按约 0.7 秒松开）、**空中普攻**（起跳后左键）、**下落攻击**（空中右键）往敌人方向挥。
   - 若 Layer 和碰撞体都设对，敌人应会**消失**（SetActive(false)）；Console 不应有报错。

3. **确认敌人死后加经验和金币**
   - 目前还没有 HUD 显示数字，可以用下面任一方式确认：
     - **临时 Log**：在 `EnemyController.Die()` 里、给玩家加完经验和金币后，加一行  
       `Debug.Log($"击杀 {_stats.enemyId}，经验+{_stats.expReward}，金币+{gold}，当前经验={player.Exp.Exp}，当前金币={player.Gold}");`  
       再杀一只怪看 Console 输出。
     - **断点**：在 `PlayerModel.AddExp` 或 `player.Gold += gold` 处打断点，杀怪时看是否命中、数值是否增加。

4. **确认精英掉落（若做了精英）**
   - 敌人用 **EnemyStats_Elite**，预制体上 **Drop Table**、**Weapon Source** 已拖好；击杀后应有机会掉武器或药剂进背包（满包则不掉），后续做背包 UI 能看到；也可在 `EnemyController.TryDropLoot` 里加临时 Log 看是否 Roll 到物品。

5. **确认难度**
   - 主菜单新游戏进关，杀几只怪记下大致血量或刀数；回主菜单再进同一档（或死亡回滚后再进），难度会 +1，同种怪应更耐打。

---

## 七、可选：精英怪与掉落表

- **DropTableSO**：**Create → Game → Drop → DropTable**，取名如 `DropTable_Level1`，**Level Index** 填 1，在 **Entries** 里加多行：**Item Type** 填 `weapon_common`、`weapon_rare`、`potion_hp`、`potion_mp`、`nectar` 等，**Weight** 填权重（数字越大越容易抽到）。
- **精英敌人预制体**：在 EnemyController 上 **Drop Table** 拖该 DropTable，**Weapon Source** 拖一个已配置好各品质范围的 **WeaponSO**，这样精英死亡会按表 Roll 一次，可能掉武器（用 WeaponSO.Roll）或药剂/仙露（进背包堆叠）。

完成以上步骤后，阶段一的「打怪 → 掉钱/经验/掉落」即可在编辑器里跑通；5 种敌人都用同一套 EnemyController，只是 SO 和预制体不同。
