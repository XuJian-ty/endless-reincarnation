# 声音设置面板：编辑器里怎么做

依据**功能需求说明书**：

- **主菜单声音设置**：三项功能——（1）复选框勾选/取消以打开或关闭主界面背景音乐；（2）滑块调节主界面背景音乐音量；（3）下拉列表选择切换主界面背景音乐曲目。数据存于 **PlayerPrefs**，**全局生效**。
- **关卡内声音设置**：五项功能——（1）复选框开关关卡内背景音乐；（2）滑块调节关卡内背景音乐音量；（3）下拉切换关卡内背景音乐曲目；（4）复选框开关音效（除关卡 BGM 外的所有音效）；（5）滑块调节音效音量。以上**按当前存档独立保存**（**JSON 存档**）。

主菜单场景点「声音设置」打开 **MainMenuSoundPanel**，关卡内菜单点「声音设置」打开 **LevelSoundPanel**。

---

## 零、BGM 曲目列表配置（ScriptableObject）

曲目列表不再在面板预制体上配置，而是用 **ScriptableObject 配置文件**。每项包含**曲目名称**（下拉框里显示的标签，可自定）和**音频**（拖入 AudioClip）。

- **主菜单 BGM 曲目**：配置文件为 **MainMenuBgmTrackListSO**，运行时从 `Resources/Config/MainMenuBgmTracks` 加载。主菜单 BGM 的开关/音量/当前曲目索引仍存 **PlayerPrefs**（全局）。
- **关卡 BGM 曲目**：配置文件为 **LevelBgmTrackListSO**，运行时从 `Resources/Config/LevelBgmTracks` 加载。关卡内 BGM 的开关/音量/曲目索引仍按**当前存档**存 **JSON**。
- **默认背景音乐**：配置里**第一项**为默认曲目（曲目索引 0）。

**创建与编辑配置：**

1. 在 Unity 菜单选 **游戏 → 创建 BGM 曲目列表配置**，会在 `Assets/Resources/Config/` 下生成 **MainMenuBgmTracks.asset** 与 **LevelBgmTracks.asset**（初始为空列表）。
2. 在 Project 中选中 **MainMenuBgmTracks** 或 **LevelBgmTracks**，在 Inspector 里展开 **曲目列表**，点击 **+** 增加元素。每项有两个字段：**曲目名称**（如「主菜单」「关卡1」等，即下拉框里显示的文案）、**音频**（从 Project 拖入对应 AudioClip）。下拉框选项与列表顺序一致，显示的就是这里填的曲目名称。
3. 若未创建配置或列表为空，则不会播放 BGM。

## 一、主菜单声音设置面板（MainMenuSoundPanel）

### 1.1 作用与命名约定

- 主菜单四个入口中的「**声音设置**」会打开此面板。
- 子控件**名字必须一致**（脚本通过 BasePanel 按名查找）：
  - **Toggle_Bgm**：背景音乐开关复选框（勾选=开，取消=关）。
  - **Slider_BgMusic**：背景音乐音量滑块（0～1）。
  - **Dropdown_BgmTrack**：背景音乐曲目下拉列表（选项由脚本根据 **MainMenuBgmTrackListSO** 配置的曲目列表生成「曲目1」「曲目2」…）。
  - **Btn_Close**：关闭按钮。
- 无需在面板上配置曲目列表，曲目从 **Resources/Config/MainMenuBgmTracks** 的 ScriptableObject 读取。

### 1.2 在场景里做出面板

1. 在 **Canvas** 下（如 **Mid** 或 **Top**）**右键 → Create Empty**，命名为 **MainMenuSoundPanel**。
2. 选中该物体，**Add Component** 搜索 **Main Menu Sound Panel**，挂上 **Main Menu Sound Panel (Script)**。
3. **做背景（可选）**：在 MainMenuSoundPanel 下 **右键 → UI → Image** 命名 **Bg**，铺满父物体。
4. **做复选框**：**右键 → UI → Toggle**，命名为 **Toggle_Bgm**，标签可写「背景音乐」。
5. **做滑块**：**右键 → UI → Slider**，命名为 **Slider_BgMusic**；Min Value = 0，Max Value = 1。脚本打开时会从 PlayerPrefs 读取并刷新。
6. **做下拉**：**右键 → UI → Dropdown**，命名为 **Dropdown_BgmTrack**。选项由脚本根据配置文件中的曲目列表自动生成，无需手动填 Option 列表。
7. **做关闭按钮**：**Button** 命名为 **Btn_Close**，文字「关闭」。脚本通过 RegisterClick 注册，无需手动挂 OnClick。
8. 排布：用 **Vertical Layout Group** 或手动摆好复选框、滑块、下拉与按钮位置。

### 1.3 做成预制体

- 在 **Hierarchy** 里选中 **MainMenuSoundPanel**（整棵），拖到 **Project 的 Resources/UI/** 下，生成预制体。
- 将预制体**重命名为 MainMenuSoundPanel**（与 `PanelNames.MainMenuSound` 对应）。
- 场景里这棵可删掉，运行时会由 UIManager 加载。

### 1.4 主菜单如何打开

- 主菜单面板（MainMenuPanel）上 **Btn_Settings** 已绑定为打开 **MainMenuSoundPanel**。主菜单进入时会根据 PlayerPrefs 应用 BGM 开关、音量与曲目（曲目列表从配置文件读取）。

## 二、关卡内声音设置面板（LevelSoundPanel）

### 2.1 作用与命名约定

- 关卡内按 **Esc** 打开菜单后，点「**声音设置**」会打开此面板。
- 子控件名字（必须一致）：
  - **Toggle_Bgm**：关卡内背景音乐开关复选框。
  - **Slider_BgMusic**：关卡内背景音乐音量滑块（0～1）。
  - **Dropdown_BgmTrack**：关卡内背景音乐曲目下拉（选项由脚本根据 **LevelBgmTrackListSO** 配置的曲目列表生成）。
  - **Toggle_SoundEffects**：音效开关复选框（除关卡 BGM 外的所有音效）。
  - **Slider_SoundEffects**：音效音量滑块（0～1）。
  - **Btn_Close**：关闭按钮。
- 无需在面板上配置曲目列表，曲目从 **Resources/Config/LevelBgmTracks** 的 ScriptableObject 读取。BGM/音效的开关与音量来自**当前存档**（JSON），调节后写回存档并立即保存。

### 2.2 在场景里做出面板

1. 在 **Canvas** 下 **右键 → Create Empty**，命名为 **LevelSoundPanel**。
2. 选中该物体，**Add Component** 搜索 **Level Sound Panel**，挂上 **Level Sound Panel (Script)**。
3. **做背景（可选）**：下挂 **Bg**（Image），铺满父物体。
4. **做 BGM 控件**：**Toggle_Bgm**、**Slider_BgMusic**（Min=0, Max=1）、**Dropdown_BgmTrack**（选项由脚本根据配置文件生成）。
5. **做音效控件**：**Toggle_SoundEffects**、**Slider_SoundEffects**（Min=0, Max=1）。
6. **做关闭按钮**：**Btn_Close**，文字「关闭」。
7. 排布好后整棵拖成预制体。

### 2.3 做成预制体与关卡 BGM 播放

- 拖到 **Resources/UI/**，预制体**重命名为 LevelSoundPanel**（与 `PanelNames.LevelSound` 对应）。
- 关卡内菜单（MenuPanel）的 **Btn_Settings** 已绑定为打开 **LevelSoundPanel**。进入关卡时 GameStateMachine 会按当前存档（JSON）应用 BGM 与音效的开关和音量。
- **关卡 BGM 曲目**：在关卡场景中可挂一个 **LevelBgmApplier (Script)**（GameFlow 下），进入关卡时会从 **LevelBgmTrackListSO** 配置读取曲目列表，并按当前存档的曲目索引自动播放对应 BGM；不挂则仅依赖打开 LevelSoundPanel 时同步曲目。

## 三、Resources 清单

| 路径/预制体 | 用途 |
|------------|------|
| **Resources/Config/MainMenuBgmTracks** | 主菜单 BGM 曲目列表配置（ScriptableObject）；主菜单 BGM 仍全局 PlayerPrefs |
| **Resources/Config/LevelBgmTracks** | 关卡 BGM 曲目列表配置（ScriptableObject）；关卡 BGM 仍按存档 JSON |
| **Resources/UI/MainMenuSoundPanel** | 主菜单「声音设置」面板：BGM 开关 + 音量滑块 + 曲目下拉（3 项） |
| **Resources/UI/LevelSoundPanel** | 关卡内「声音设置」面板：BGM 开关 + BGM 音量 + BGM 曲目 + 音效开关 + 音效音量（5 项，按存档保存） |

---

## 四、测试

1. **主菜单**：运行主菜单场景，点「**声音设置**」→ 弹出 **MainMenuSoundPanel**，应有**复选框、BGM 滑块、曲目下拉、关闭**。勾选/取消、调滑块、换曲目后关闭再打开或重启游戏，状态应保持（PlayerPrefs）。曲目列表来自 **MainMenuBgmTracks** 配置。
2. **关卡内**：进关卡后按 **Esc** → 「**声音设置**」→ **LevelSoundPanel**，应有 **BGM 开关、BGM 滑块、BGM 曲目下拉、音效开关、音效滑块、关闭**。调节后关闭，再读档或重进该存档，应为该存档保存的值（JSON）；换存档进关卡再开声音设置，应为该存档自己的设置，互不影响。曲目列表来自 **LevelBgmTracks** 配置。
