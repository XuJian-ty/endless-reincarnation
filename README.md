# 无尽轮回

一款使用 Unity 开发的第三人称 3D 动作游戏，目前支持 Windows 和 Android。游戏包含近战、远程、技能、装备、关卡探索、首领战、角色成长和存档功能，也可以通过好友援助共同进入关卡。

## 演示下载

- [观看游戏演示](https://github.com/XuJian-ty/endless-reincarnation/releases/latest/download/EndlessReincarnation-Demo.mp4)
- [下载 Android APK](https://github.com/XuJian-ty/endless-reincarnation/releases/latest/download/EndlessReincarnation-Android.apk)

APK 适用于 Android 64 位设备。

## 主要内容

- 第三人称近战、远程攻击、闪避和技能释放。
- 多个关卡、检查点、敌人、首领、宝箱和掉落物。
- 背包、装备、商店、技能树和角色属性成长。
- 本地存档、账号存档、好友、聊天和好友援助。
- 键鼠操作和 Android 横屏触控。

## 技术栈

- Unity 2023.2、C#、URP、Input System
- ASP.NET Core 8、EF Core、MySQL
- HTTP API、WebSocket、Docker Compose
